## はじめに

ポケモンカードには、ネストボールやハイパーボールのように「山札から対象外のカード（例：たねポケモンや特定のカードタイプ）を探して手札に加える」タイプのグッズがあります。こうしたカードを使うと、目当てのカード（例えばアタッカーの進化先や重要なサポート）以外のカードが山札から減っていくため、「山札が圧縮されて、目当てのカードを引きやすくなる」という言い方をよく耳にします。

しかし、この「デッキ圧縮」の効果は、実際にはどれくらいのものなのでしょうか。「サーチを1枚使えば、実質的にもう1枚多くドローしたのと同じくらい引きやすくなる」というイメージを持っている方も多いかもしれませんが、これは厳密には正しくありません。この記事では、超幾何分布を使ってデッキ圧縮の効果を正確に計算し、「ただの追加ドロー」とどれくらい違うのかを比較します。

## 計算方法（超幾何分布の式）

超幾何分布の基本式は以下の通りです。

```
P(X = k) = C(K, k) × C(N-K, n-k) / C(N, n)
```

- `N`：山札の残り枚数
- `K`：目当てのカードの残り枚数
- `n`：これから引く枚数
- `k`：その中で目当てのカードが出た枚数

「1枚以上引ける確率」は `P(X ≥ 1) = 1 − C(N-K, n) / C(N, n)` で求められます。

ここでデッキ圧縮を数式に落とし込むと、次のように整理できます。サーチカードで「目当てのカードではない」と分かっているカードを w枚、山札から確実に取り除いたとします。すると、目当てのカードの枚数 K はそのままで、山札の残り枚数だけが `N` から `N − w` に減ります。つまり、圧縮後にn枚を引いたときに1枚以上ヒットする確率は、

```
P(X ≥ 1 | 圧縮w枚) = 1 − C(N−w−K, n) / C(N−w, n)
```

となります。一方、「w枚を余分にランダムドローする」場合は、山札の枚数 `N` はそのままで引く枚数を `n + w` に増やすことになるため、

```
P(X ≥ 1 | 追加ドローw枚) = 1 − C(N−K, n+w) / C(N, n+w)
```

という別の式になります。この2つの式は見た目が似ていますが、意味はまったく異なります。圧縮では「ハズレだと確定しているカード」だけを取り除くのに対し、追加ドローでは引いたw枚の中に目当てのカード自体が混ざっている可能性もあるため、追加ドローの方がヒット率を大きく押し上げます。

## 具体例

60枚デッキに目当てのカードを3枚採用しているとします（K=3）。初手8枚（n=8）の時点でこのカードが1枚以上来る確率は、以前の記事でも扱った通り約35.4%です。ここでは「初手にはまだ来ていない」状態、つまり残り52枚の山札にK=3枚がそのまま残っている状態からスタートし、そこから4枚（数ターン分のドローに相当、m=4）を引く場合を考えます。

圧縮なしの場合、

```
P(X≥1) = 1 − C(49, 4) / C(52, 4) ≒ 0.2174（約21.7%）
```

ここでネストボールなどのサーチカードを2枚使い、目当てのカードではない別のたねポケモンを2枚、山札から確実に手札へ移したとします（w=2）。すると山札の残りは50枚、目当てのカードは変わらず3枚のままなので、

```
P(X≥1 | 圧縮2枚) = 1 − C(47, 4) / C(50, 4) ≒ 0.2255（約22.6%）
```

圧縮なしの約21.7%から約22.6%へと、約0.8ポイントしか上がりません。一方、もしこの2枚を単純に追加でランダムドローしていたら（m=4+2=6枚）、

```
P(X≥1 | 追加ドロー2枚) = 1 − C(49, 6) / C(52, 6) ≒ 0.3131（約31.3%）
```

約31.3%まで上昇します。同じ「2枚分の山札操作」でも、圧縮による上昇幅（+0.8ポイント）と、追加ドローによる上昇幅（+9.6ポイント）には10倍以上の差があることが分かります。

## 実戦での考察

冒頭の表からも分かるように、圧縮枚数を増やしても目当てのカードを引く確率はごくわずかしか上昇しません。w=10枚というかなり大がかりな圧縮を行っても、約21.7%から約26.5%への上昇にとどまります。これに対し、同じ10枚を単純に追加ドローできれば約61.8%まで跳ね上がります。

この差が生まれる理由はシンプルで、圧縮は「目当てのカードではないと確定しているカードだけ」を取り除く操作だからです。山札の総量は減りますが、目当てのカードの絶対数（K）は変わらないため、比率（K/N）の改善は緩やかにしか進みません。それに対して追加ドローは、引いた分だけ目当てのカード自体を引き当てるチャンスが単純に増えるため、効果がまったく別次元になります。

ではデッキ圧縮に意味がないかというと、そうではありません。ネストボールやハイパーボールのようなサーチカードの本当の価値は、「山札の目当てのカードを引く確率をわずかに上げること」ではなく、「サーチ対象そのもの（たねポケモンなど）を100%の確率で手札に加えられること」にあります。デッキ圧縮による副次的な確率上昇はあくまでおまけ程度と捉え、「このカードを使えば欲しいカードが劇的に引きやすくなる」という過度な期待は禁物です。圧縮効果を主目的にしたいのであれば、その分の投資はドロー・サーチ枚数そのものを増やすことに使った方が、確率上のリターンは大きくなります。

## まとめ

- デッキ圧縮（対象外のカードをサーチで山札から取り除くこと）は、目当てのカードの残り枚数Kはそのままに、山札の総枚数Nだけを減らす操作である
- 圧縮による目当てのカードのヒット率上昇は `1 − C(N−w−K, n) / C(N−w, n)` で計算でき、上昇幅はごくわずか（w=10枚でも+5ポイント弱）にとどまる
- 同じw枚を単純に追加ドローできた場合の上昇幅（w=10枚で+40ポイント超）と比べると、圧縮の効果は10倍以上小さい
- サーチカードの主な価値は「圧縮によるヒット率上昇」ではなく「サーチ対象を確実に手札に加えられること」にある

「デッキを掘れば掘るほど欲しいカードが出やすくなる」という感覚は半分正しく半分言い過ぎ、というのが厳密な計算から見えてくる結論です。自分のデッキのカード構成でどれくらいの差になるのか気になる方は、「ポケカデッキ分析ツール」で採用枚数や引く枚数を変えながら実際の数値を確認してみてください。
