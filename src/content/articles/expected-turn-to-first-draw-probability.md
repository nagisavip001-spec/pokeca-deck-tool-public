## はじめに

このツールのコラムでは、これまで「初手8枚に1枚以上引ける確率」や「何ターン目までに累計で何%引けているか」といった、**ある時点を決めてそこでの確率を計算する**記事を多く扱ってきました。

しかし確率の捉え方には、もう一つ別の切り口があります。それが「目当てのカードは、平均して何枚目（何ターン目）に出てくるのか」という**待ち時間そのものの期待値**です。これは「何ターン目で引ける確率が50%を超えるか」という“真ん中の値（メディアン）”とも違う、“平均の値（平均値・期待値）”を求める計算です。この記事では、超幾何分布の考え方を使って、カードが初めて手札に来るまでの枚数・ターン数の期待値を厳密に計算し、採用枚数によってどう変わるのかを見ていきます。

## 計算方法（超幾何分布の式）

60枚のデッキをシャッフルして1枚目から順番に並べたと考えると、目当てのカード（K枚）が最初に出てくる位置（何枚目か）は、デッキの枚数Nと採用枚数Kだけで決まる分布に従います。これは超幾何分布そのものではなく、超幾何分布から派生する「待ち時間の分布（負の超幾何分布）」ですが、組み合わせの数え方は超幾何分布と同じ `C(a, b)` の考え方を使います。

まず、「最初のm枚の中に目当てのカードが1枚もない」確率を考えます。これは超幾何分布の `k=0` のケースと同じ形です。

```
P(最初のm枚に0枚) = C(N-m, K) / C(N, K)
```

この「m枚見てもまだ1枚も引けていない確率」を m = 0, 1, 2, … と足し上げていくと、「初めて引けるまでの枚数」の期待値になります。

```
E[何枚目で引けるか] = Σ P(最初のm枚に0枚) = (N + 1) / (K + 1)
```

- `N`：デッキの総枚数（通常60枚）
- `K`：デッキ内の目当てのカードの採用枚数

驚くほど単純な式になりますが、これは実際に `N=60, K=1` を小さいNで試すと確かめられます。たとえばN=3、K=1（カード1枚だけを3枚の山に混ぜる）なら、その1枚は等確率で1枚目・2枚目・3枚目のどこかに来るので、平均は(1+2+3)/3=2枚目です。式に当てはめても `(3+1)/(1+1)=2` となり、一致します。

この「何枚目か」という位置を、このツールの他の記事と同じ「後攻視点・初手8枚（7枚スタート＋1枚ドロー）」という前提でターン数に変換すると、次の関係になります。

```
ターン数T = (何枚目か) − 7　（Tが1未満なら初手8枚の中に収まっている計算）
```

## 具体例：採用枚数4枚の場合

デッキ60枚に4枚採用しているカード（K=4）を例に計算してみます。

```
E[何枚目で引けるか] = (60 + 1) / (4 + 1) = 61 / 5 = 12.2（枚目）
ターン数 = 12.2 − 7 = 5.2（後攻5ターン目あたり）
```

つまり4枚採用のカードは、平均すると**後攻5ターン目あたりで初めて手札に来る**計算になります。ここで気になるのが、「じゃあ後攻5ターン目の時点で、実際に何%の確率で引けているのか」という点です。これは別途、通常の超幾何分布の累積確率の式で計算できます。

```
P(X ≥ 1 | n=12) = 1 − C(56, 12) / C(60, 12) ≒ 0.601（約60.1%）
```

**平均の到達タイミングである後攻5ターン目の時点で、すでに約60.1%の確率で引けている**という結果になります。半分より明らかに高い数字です。これは偶然ではなく、待ち時間の分布には構造的な理由があります。

## 採用枚数を増やすとどう変わるか

冒頭の表を見ると、どの採用枚数でも「平均到達タイミングでの実際の到達率」は必ず50%を上回っており、採用枚数が増えるほどその値はさらに高くなっていく（64.0%→97.0%）ことが分かります。これは、待ち時間の分布が**右に長く裾を引く形**をしているためです。多くのケースでは目当てのカードは平均より早めに出てきますが、ごく一部、デッキの最後の方まで出てこない「大外れ」のケースがあり、その「大外れ」が平均値を後ろに強く引き伸ばします。結果として、平均値は「真ん中（メディアン）」より遅い側に寄るため、平均タイミングに到達した時点では、すでに半分より多くのケースで引けている、という一見不思議な現象が起こります。

もう一つ注目したいのは、採用枚数を増やしたときの平均到達タイミングの縮み方です。

- 1枚→2枚：後攻24ターン目相当 → 後攻13ターン目相当（約半分）
- 2枚→4枚：後攻13ターン目相当 → 後攻5ターン目相当（半分弱）
- 4枚→6枚：後攻5ターン目相当 → 後攻2ターン目相当

採用枚数を2倍にすると平均到達タイミングはおおよそ半分になるという、`E=(N+1)/(K+1)` の式がそのまま反映されたきれいな反比例の関係が見えます。1枚しか積めないカード（ACE SPECなど）ほど、わずかな採用枚数の差が平均到達タイミングに大きく響くということが、この期待値の視点からも裏付けられます。

実戦的には、「何ターン目までに何%引けるか」という累積確率の表と、この「平均して何ターン目に来るか」という期待値は、同じ超幾何分布から出発していても見ている角度が異なります。累積確率は「このターンまでに間に合う可能性」を測るのに向いており、期待値は「平均的にはどれくらい待つことになるか」という、より素朴な感覚に近い数字を与えてくれます。両方を知っておくと、「引けたらラッキー」で済ませられるカードなのか、「それなりの枚数を見るまで待つ必要がある」カードなのかを、より多面的に判断できます。

## まとめ

- 目当てのカードが初めて引けるまでの枚数の期待値は、超幾何分布から導かれる `E = (N + 1) / (K + 1)` という単純な式で計算できる
- 4枚採用なら平均で約12.2枚目（後攻5ターン目あたり）、1枚採用なら平均で約30.5枚目（後攻24ターン目あたり）が目安になる
- 採用枚数を2倍にすると、平均到達タイミングはおおよそ半分になる反比例の関係がある
- 待ち時間の分布は右に裾が長いため、「平均到達タイミング」の時点では、実際の到達率はすでに50%を明確に超えている
- 「何ターン目までに何%引けるか」という累積確率と、「平均して何ターン目に来るか」という期待値は、同じ計算の別の見方であり、両方を知ることでカードの引きやすさをより立体的に把握できる

採用枚数を検討する際は、累積確率の表だけでなく、この「平均してどれくらい待つことになるか」という感覚も持っておくと、デッキの設計やマリガン・引き直しの判断材料がより具体的になります。
