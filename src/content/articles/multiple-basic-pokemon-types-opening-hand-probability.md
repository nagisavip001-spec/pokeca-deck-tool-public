## はじめに

ポケカのデッキ構築というと、「たね→1進化→2進化」と1本の進化ラインを揃えていくイメージが強いかもしれません。しかし実際には、性質の異なる複数のたねポケモンを1つのデッキに同居させる構築も珍しくありません。たとえば次のようなケースです。

- 対面によって主力を使い分ける、複数の単ポケモン（無進化）アタッカーを並行採用したデッキ
- 序盤の場持ち要員（にげる・特性目的のたねポケモン）とアタッカー用のたねポケモンを別々に採用したデッキ
- 1進化ラインを2系統採用し、初手ではどちらの「たね」でもいいから展開したいデッキ

こうした構築で気になるのは、「マリガンにならないか（たねポケモンが1枚でもあるか）」だけではありません。**初手8枚の中に、性質の異なる複数のたねポケモンのうち何種類が同時に含まれているか**が、序盤の展開力を大きく左右します。1種類しか来なければ選択肢がなく、2種類・3種類とそろえば対面に応じた立ち回りが取れます。

この記事では、デッキに3種類の異なるたねポケモンを採用した場合に、初手8枚の中でそのうち「3種類とも」「2種類以上」がそろう確率を、超幾何分布と包除原理（インクルージョン・エクスクルージョン）を使って厳密に計算します。

## 計算方法（超幾何分布の式）

超幾何分布の基本式はこうでした。

```
P(X = k) = C(K, k) × C(N-K, n-k) / C(N, n)
```

- `N`：デッキの総枚数（通常60枚）
- `K`：対象カードの採用枚数
- `n`：引く枚数（この記事では初手8枚で統一します）
- `k`：その中に対象カードが含まれる枚数

今回考えたいのは、3種類のたねポケモンA（`K_A`枚）・B（`K_B`枚）・C（`K_C`枚）について、「初手8枚の中にA・B・Cがそれぞれ1枚以上含まれているか」です。これは3つの集合を扱う問題なので、単独の超幾何分布だけでは足りず、包除原理で組み合わせます。

まず、「Aが1枚も来ない」「Bが1枚も来ない」「Cが1枚も来ない」という3つの事象を考えます。特定のカード群が丸ごと初手に0枚である確率は、それらのカード群を除いた残りの山札だけから8枚を選ぶ場合の数で計算できます。

```
P(Aが0枚) = C(N-K_A, n) / C(N, n)
P(Aが0枚 かつ Bが0枚) = C(N-K_A-K_B, n) / C(N, n)
P(Aが0枚 かつ Bが0枚 かつ Cが0枚) = C(N-K_A-K_B-K_C, n) / C(N, n)
```

「A・B・Cの少なくとも1種類が0枚」になる確率は、包除原理を使って次のように求まります。

```
P(いずれかが0枚) = P(A=0)+P(B=0)+P(C=0)
                   − P(A=0,B=0) − P(A=0,C=0) − P(B=0,C=0)
                   + P(A=0,B=0,C=0)
```

「3種類ともそろう確率」は、この余事象として求められます。

```
P(3種類ともそろう) = 1 − P(いずれかが0枚)
```

さらに、「2種類以上そろう確率」は、「0種類」と「ちょうど1種類だけ」の確率を1から引くことで求められます。「Aだけそろう（B・Cは0枚）」確率は `P(B=0,C=0) − P(A=0,B=0,C=0)` で計算でき、B・Cについても同様に計算して合計します。

```
P(0種類) = P(A=0,B=0,C=0)
P(Aのみ) = P(B=0,C=0) − P(A=0,B=0,C=0)
P(ちょうど1種類) = P(Aのみ) + P(Bのみ) + P(Cのみ)
P(2種類以上) = 1 − P(0種類) − P(ちょうど1種類)
```

## 具体例

3種類のたねポケモンを**それぞれ3枚ずつ（合計9枚）**採用した場合で計算してみます。

- `N = 60`、`n = 8`
- `K_A = K_B = K_C = 3`

まず必要な部品を計算します。

```
P(A=0) = C(57, 8) / C(60, 8) ≒ 0.6458
P(A=0, B=0) = C(54, 8) / C(60, 8) ≒ 0.4067
P(A=0, B=0, C=0) = C(51, 8) / C(60, 8) ≒ 0.2489
```

対称性により `P(B=0)=P(C=0)`、`P(A=0,C=0)=P(B=0,C=0)` も同じ値になるので、包除原理の式に代入します。

```
P(いずれかが0枚) = 3×0.6458 − 3×0.4067 + 0.2489 ≒ 0.9664
P(3種類ともそろう) = 1 − 0.9664 ≒ 0.0336（約3.4%）
```

次に「2種類以上そろう確率」も計算します。

```
P(0種類) = 0.2489（約24.9%）
P(Aのみ) = 0.4067 − 0.2489 ≒ 0.1578
P(ちょうど1種類) = 3×0.1578 ≒ 0.4733（約47.3%）
P(2種類以上) = 1 − 0.2489 − 0.4733 ≒ 0.2778（約27.8%）
```

つまり、3種3枚ずつの構築では「1種類も来ない」確率が約24.9%、「ちょうど1種類だけ」が約47.3%と最も多く、「2種類以上そろう」のは約27.8%、「3種類フルにそろう」のはわずか約3.4%にとどまります。1種類のたねポケモンだけなら初手ヒット率はそれなりに高くても、複数種類を同時にそろえるハードルは一気に上がることが分かります。

## 採用枚数を増やすとどう変わるか、または実戦での考察

冒頭の表を見ると、いくつか実戦に役立つ傾向が読み取れます。

**採用枚数を増やす効果は大きい。** 2-2-2枚（合計6枚）では2種類以上そろう確率が約14.8%しかありませんが、4-4-4枚（合計12枚）まで増やすと約41.3%まで上がります。1種類あたりの採用枚数を1〜2枚増やすだけで、複数種そろう確率は大きく改善します。

**同じ合計採用枚数なら、配分は均等にした方が有利。** 表の3-3-3枚（合計9枚）と2-3-4枚（合計9枚）を比べると、合計採用枚数は同じでも、均等配分の3-3-3枚の方が「3種類ともそろう確率」（約3.4% vs 約3.0%）も「2種類以上そろう確率」（約27.8% vs 約26.9%）もわずかに高くなります。これは、不均等な配分では「採用枚数が少ないカード」がボトルネックになり、全体の到達率を押し下げてしまうためです。3種類とも同じくらい重要なら、可能な限り均等に振り分けた方が複数種をそろえやすいということになります。

**「全部そろう」より「2種類以上」を目標にする方が現実的。** 4-4-4枚のフル採用に近い構成でも、3種類が完全にそろう確率は約6.9%しかありません。一方で「2種類以上（どちらか対応できればOK）」という基準であれば約41.3%まで上がります。実戦では3種類全部が同時に来ることを前提にするのではなく、「2種類そろえば十分機能する」という設計にしておくと、序盤の事故率を現実的な水準に抑えられます。3種類目は初手で来なくても、2ターン目以降のドローやサーチカードで補完する、という構築・プレイングが現実的です。

## まとめ

- 複数の異なるたねポケモンが初手に何種類そろうかは、超幾何分布と包除原理を組み合わせて計算できる
- `P(3種類ともそろう) = 1 − P(いずれかが0枚)`、`P(2種類以上) = 1 − P(0種類) − P(ちょうど1種類)` で求められる
- 3枚ずつ（合計9枚）採用しても、3種類が初手で完全にそろう確率は約3.4%と低い
- 同じ合計採用枚数なら、配分を均等にした方が複数種をそろえやすい
- 「3種類フルにそろう」ではなく「2種類以上そろえば動ける」設計の方が、実戦では現実的な目標になる

複数のたねポケモンを併用する構築を考えている方は、各カードの採用枚数だけでなく、その配分バランスにも注目してみてください。自分のデッキで具体的な数字を確認したい場合は、「ポケカデッキ分析ツール」でデッキリストを入力してシミュレーションしてみることをおすすめします。
