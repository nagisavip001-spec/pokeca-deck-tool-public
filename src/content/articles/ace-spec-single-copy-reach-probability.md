## はじめに

ポケモンカードには「ACE SPEC」という特別枠のカードがあります。ACE SPECは効果こそ強力ですが、「ACE SPECは、同じ名前のカードであってもデッキに1枚しか入れられない」という、通常の「同名カード4枚まで」ルールとは別の、より厳しい制限がかかっています。つまり、どれだけ強いACE SPECでも、**採用枚数は常にK=1で固定**されてしまうということです。

これは単に「採用枚数が少ない」という話ではありません。通常のカードなら「2枚採用にしようか、4枚に増やそうか」という調整の余地がありますが、ACE SPECにはその余地そのものが存在しません。この記事では、K=1に固定された状態で、初手や各ターンまでにどれくらいの確率でACE SPECを引けているのかを超幾何分布で厳密に計算し、通常の採用枚数2〜4枚のカードと並べて、その差がどれほど大きいのかを具体的な数字で確認します。

## 計算方法（超幾何分布の式）

ここでも基本となるのは超幾何分布の式です。

```
P(X = k) = C(K, k) × C(N-K, n-k) / C(N, n)
```

- N：デッキ全体の枚数（通常60枚）
- K：デッキ内の目当てのカードの枚数（ACE SPECなら常にK=1）
- n：これまでに見たカードの枚数（初手＋ドロー済みの枚数）
- k：その中で目当てのカードが出た枚数

「少なくとも1枚引けている確率」は、1枚も引けていない確率（k=0）を1から引けば求まります。

```
P(X ≥ 1) = 1 − C(N-K, n) / C(N, n)
```

ACE SPECのようにK=1のときは、この式が綺麗に簡略化できます。K=1、k=1を代入すると、

```
P(X = 1) = C(1,1) × C(N-1, n-1) / C(N, n)
         = C(N-1, n-1) / C(N, n)
         = n / N
```

という形になります。つまり、**K=1のカードを「見た枚数nの中に引けている確率」は、単純に「n ÷ N」という比率そのもの**になるのです。これは、60枚のデッキの中にただ1枚だけ混ぜたカードが、ランダムに抜き出したn枚のどこかに入っている確率を考えているだけなので、直感的にも納得しやすい結果です。一方、K=2以上になると式はこの単純な比率では表せなくなり、C(N-K, n)の計算が必要になります。

## 具体例：初手8枚でACE SPECを引ける確率

N=60、K=1（ACE SPEC）、n=8（後攻1ターン目の初手）で計算してみます。

```
P(X ≥ 1) = n / N = 8 / 60 ≒ 0.133（約13.3%）
```

約7.5回に1回しか初手に来ない計算です。同じ条件で4枚採用のカードなら約44.5%なので、**ACE SPECは同じ「見た枚数」でも4枚採用カードの3分の1程度しか初手に来ない**ことになります。

さらに、「累計で引けている確率が50%を超えるのは何ターン目か」を計算すると、この差はより際立ちます。

- K=4（4枚採用）：n=10（後攻3ターン目）で約52.8%に到達
- K=3（3枚採用）：n=13（後攻6ターン目）で約52.6%に到達
- K=2（2枚採用）：n=18（後攻11ターン目）で約51.4%に到達
- K=1（ACE SPEC）：**n=30（後攻23ターン目）でようやく約50.0%に到達**

4枚採用のカードなら3ターン目には五分五分まで来ているのに対し、ACE SPECは23ターン目まで引き続けてようやく五分五分、という計算になります。実際の試合がそこまで長引くことは稀なので、「ACE SPECは引けたら強いが、引けること自体をあてにしたプランは組みにくい」という感覚が、数字の上でも裏付けられます。

## 採用枚数を増やすとどう変わるか（増やせないことの実戦的な意味）

通常のカードであれば、ここで「採用枚数を増やすとどう改善するか」を検討するのが定石ですが、ACE SPECはルール上それができません。そこで実戦では、次の2つの方向で「K=1の弱さ」を補うことになります。

**1. サーチ手段でカバーする**
ACE SPECの多くはトレーナーズ（グッズやサポート）であり、ポケモンを対象とするサーチカード（ネストボールやハイパーボールなど）では直接探せません。デッキ内の「どのカードでも1枚引ける」系の効果や、山札を掘るドロー系サポートと組み合わせることで、見かけ上のnを早く増やし、到達率を少しでも引き上げる工夫が必要になります。

**2. 「引けなくても成立する」構築にする**
表の通り、K=1のカードは中盤になってもなかなか50%に届きません。そのため、ACE SPECを「それがなければ勝てないデッキの核」として扱うのではなく、「引けたら試合を楽にする追加のプラン」として設計するデッキが多くなります。ACE SPECに依存しすぎた試合プランは、計算上かなりの確率で「引けないまま試合が終わる」ことを前提にしておく必要があります。

また、サイド落ちのリスクも通常のカードより重く効きます。1枚しか入れられない以上、サイドに落ちてしまえば山札側の残存枚数はゼロになり、その試合では二度と引けません。K=4なら1枚がサイドに落ちても残り3枚でカバーできますが、K=1にはその保険が存在しません。

## まとめ

- ACE SPECは「同名4枚まで」の通常ルールとは別に「1枚まで」という特別な制限を持ち、採用枚数は常にK=1に固定される
- K=1のときの到達率は超幾何分布の式が簡略化され、`P(X≥1) = n / N` という単純な比率になる
- 初手8枚での到達率は約13.3%で、4枚採用カード（約44.5%）の3分の1程度にとどまる
- 累計到達率が50%を超えるのに、K=4なら後攻3ターン目で済むのに対し、K=1は後攻23ターン目までかかる
- 採用枚数を増やせない以上、サーチ手段でのカバーや「引けなくても成立する」構築で弱点を補う必要がある

ACE SPECを採用するかどうかを検討するときは、効果の強さだけでなく「K=1という構造的な引きづらさ」もセットで考えておくと、試合中の見切りや構築判断がしやすくなります。気になるカードの採用枚数や到達率は、「ポケカデッキ分析ツール」でも具体的な数字で確認できます。
