## はじめに

ポケカのデッキには、「このカードとこのカードが両方そろえば強い」という組み合わせだけでなく、「この3枚のうちどれか1枚でもあれば十分」という場面も多くあります。たとえば次のような状況です。

- 盤面の入れ替えに使える手段（あなぬけのひも・ポケモンいれかえ・ともだちてちょうなど）を複数種類採用しており、どれか1枚あれば逃げ切れる
- ベンチを呼び出すサポートを複数系統採用しており、どれか1枚使えれば十分に機能する
- 似た役割の1進化ポケモンを何種類か採用しており、どれか1体が立てば試合を組み立てられる

こうした「どれか1枚でもあればOK」という条件（以下、**OR条件**）は、以前の記事で扱った「3種類とも同時にそろわないと機能しない」条件（**AND条件**）とは、確率の挙動が大きく異なります。同じ合計採用枚数でも、OR条件とAND条件では到達率にどれほどの差が出るのか、そしてカードの配分（均等か不均等か）が結果にどう影響するのかを、超幾何分布と包除原理を使って厳密に計算し比較します。

## 計算方法（超幾何分布の式）

超幾何分布の基本式はこうでした。

```
P(X = k) = C(K, k) × C(N-K, n-k) / C(N, n)
```

- `N`：デッキの総枚数（通常60枚）
- `K`：対象カードの採用枚数
- `n`：引く枚数（この記事では初手8枚で統一します）
- `k`：その中に対象カードが含まれる枚数

今回は、異なる3種類のカードA（`K_A`枚）・B（`K_B`枚）・C（`K_C`枚）を採用している前提で、**OR条件**と**AND条件**をそれぞれ計算します。

**OR条件（少なくとも1種類来る確率）** の否定は「A・B・Cが全部0枚」です。A・B・Cはカードとして重複しない別々のグループなので、この3グループを合わせた「どれでもないカード」から8枚を選ぶ場合の数を考えればよく、次のシンプルな式になります。

```
P(いずれも0枚) = C(N − K_A − K_B − K_C, n) / C(N, n)
P(OR条件が成立) = 1 − C(N − K_A − K_B − K_C, n) / C(N, n)
```

これは実質的に「`K = K_A + K_B + K_C` 枚の1種類のカード」を考えたときの `1 − P(X=0)` と完全に同じ式です。つまり**OR条件は、3種類の採用枚数を単純に合計した1つの超幾何分布として計算できる**ということがポイントです。

一方、**AND条件（3種類とも1枚以上来る確率）** は、以前の記事でも扱ったとおり包除原理が必要です。

```
P(いずれかが0枚) = P(A=0)+P(B=0)+P(C=0)
                   − P(A=0,B=0) − P(A=0,C=0) − P(B=0,C=0)
                   + P(A=0,B=0,C=0)

P(AND条件が成立) = 1 − P(いずれかが0枚)
```

OR条件が「合計枚数」だけで決まる単純な足し算であるのに対し、AND条件は各カードの枚数をそれぞれ個別に式へ組み込む必要があり、計算の手間も結果の挙動も大きく異なります。

## 具体例

デッキ60枚の中に、異なる3種類のカードを**合計9枚**採用する場合を、配分パターンを変えて比較します。

**均等配分（3-3-3枚）の場合**

```
N = 60、K_A = K_B = K_C = 3、合計 = 9
P(いずれも0枚) = C(51, 8) / C(60, 8) ≒ 0.2489
P(OR条件) = 1 − 0.2489 ≒ 0.7511（約75.1%）
P(AND条件) ≒ 0.0336（約3.4%）
```

**不均等配分（1-3-5枚）の場合**

```
N = 60、K_A = 1、K_B = 3、K_C = 5、合計 = 9
P(いずれも0枚) = C(51, 8) / C(60, 8) ≒ 0.2489（3-3-3枚と完全に同じ）
P(OR条件) = 1 − 0.2489 ≒ 0.7511（約75.1%、3-3-3枚と全く同じ）
P(AND条件) ≒ 0.0187（約1.9%）
```

合計採用枚数が同じ9枚であれば、OR条件の到達率は配分に関係なく**完全に同じ約75.1%**になります。一方でAND条件は、均等配分なら約3.4%あった到達率が、1-3-5枚という偏った配分にすると約1.9%まで下がってしまい、合計枚数が同じでも配分次第で到達率が2倍近く変わります。

## 採用枚数を増やすとどう変わるか、または実戦での考察

冒頭の表から読み取れることをまとめます。

**OR条件は配分を気にする必要がない。** 6枚・9枚・12枚のいずれの合計枚数でも、2-2-2枚と1-2-3枚、3-3-3枚と2-3-4枚と1-3-5枚は、それぞれ完全に同じOR到達率になっています。これは、OR条件が「3種類の合計がどれだけあるか」だけで決まり、「どのカードに何枚振り分けたか」には一切影響されないためです。実戦で言えば、「逃げ道になるカードを何種類採用するか」を考えるとき、種類ごとの枚数バランスに神経質になる必要はなく、**合計の枚数さえ確保できていればどの配分でも到達率は変わらない**ということになります。

**AND条件は配分が到達率を大きく左右する。** 同じ合計9枚でも、均等配分（3-3-3枚）の約3.4%に対し、偏った配分（1-3-5枚）では約1.9%まで落ち込みます。これは以前の記事でも触れたとおり、AND条件では採用枚数が最も少ないカードがボトルネックになりやすいためです。複数のカードが**同時に**必要なコンボを組む場合は、合計枚数だけでなく、個々のカードの枚数を均等に近づけることが到達率を上げる鍵になります。

**OR条件とAND条件の差そのものも非常に大きい。** 合計9枚という同じ投資でも、OR条件なら約75.1%に到達できるのに対し、AND条件（均等配分でも）は約3.4%にとどまります。これは約22倍の差です。「3種類のうちどれか1枚あればよい」という設計にできるなら、デッキの安定性を大きく引き上げられるということを、この数字は明確に示しています。

実戦に置き換えると、「同じ役割を果たせる手段を複数種類用意しておく（OR条件化する）」ことは、「複数のパーツが同時にそろわないと機能しないコンボを組む（AND条件のまま）」よりも、はるかに事故率を抑えられる構築方針だと言えます。もちろんコンボ自体の強さやカードパワーとのトレードオフはありますが、「替えが効く設計にできないか」を一度検討してみる価値は十分にあるでしょう。

## まとめ

- OR条件（3種類のうちどれか1種類以上あればよい）の到達率は `1 − C(N − K_A − K_B − K_C, n) / C(N, n)` という単純な式で求まり、**合計採用枚数だけで決まり、配分には影響されない**
- AND条件（3種類とも同時に必要）の到達率は包除原理が必要で、**同じ合計枚数でも配分が偏ると到達率が大きく下がる**
- 合計9枚という同じ投資でも、OR条件なら約75.1%、AND条件（均等配分）なら約3.4%と、約22倍の差がつく
- デッキ構築で「同じ役割を複数のカードに分散できないか」を考えることは、安定性を高める有効な手段になる
