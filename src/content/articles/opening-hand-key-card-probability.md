## はじめに

ポケモンカードを始めたばかりの頃、こんな経験はありませんか。

「エネルギーを4枚しか入れていないのに、初手で1枚も引けなかった…」
「サーチ役や展開に繋がるキーカードが、初手に全然来ない…」

これは運が悪かっただけではなく、実は**確率的にそれなりの頻度で起こる**ことなのです。この記事では、初手8枚（先攻・後攻どちらも最初に配られる手札）で目当てのカード――特定のエネルギーや、展開の起点になるキーカード、コンボに繋がるカードなど――を1枚以上引ける確率を、数学的にきちんと計算する方法を解説します。

計算の考え方さえ理解してしまえば、「このカードは何枚採用すればいいのか」という採用枚数の判断にも自信が持てるようになります。

## 超幾何分布とは何か

ポケカのデッキは60枚で、そこから何枚かを引く、という操作を数学的に扱うときに使われるのが**超幾何分布**です。トランプや福引きの確率計算と同じ考え方で、「箱の中に当たりがいくつか入っていて、そこから何個か取り出したときに当たりが何個出るか」という状況を表します。

超幾何分布の確率は、次の式で計算されます。

```
P(X = k) = C(K, k) × C(N-K, n-k) / C(N, n)
```

それぞれの記号の意味は以下の通りです。

- `N`：デッキの総枚数（通常は60枚）
- `K`：デッキの中にある「当たりカード」の枚数（例：採用している目当てのカードの枚数）
- `n`：引く枚数（初手なら8枚）
- `k`：その中で当たりが出てほしい枚数
- `C(a, b)`：a枚の中からb枚を選ぶ組み合わせの数（コンビネーション）

「初手で当たりが1枚も引けない確率」を考えるときは `k = 0` を使うのがポイントです。そして「1枚以上引ける確率」は `1 - P(X = 0)` で求められます。

## 具体例：目当てのカード4枚採用の場合

たとえば、目当てのカードを**4枚**採用しているデッキを考えます。初手8枚の中に、そのカードが1枚も入っていない確率を計算してみましょう。

- `N = 60`（デッキ枚数）
- `K = 4`（採用している目当てのカードの枚数）
- `n = 8`（初手の枚数）
- `k = 0`（1枚も引けない）

式に当てはめると、

```
P(X = 0) = C(4, 0) × C(56, 8) / C(60, 8)
```

`C(4, 0) = 1`（4枚から0枚選ぶ方法は1通り）で、残りの56枚（当たり以外のカード）から8枚選ぶ組み合わせを、デッキ60枚から8枚選ぶ組み合わせで割ります。これを計算すると、

```
P(X = 0) ≈ 0.555（約55.5%）
```

つまり、**目当てのカードを4枚しか採用していない場合、初手でそのカードを1枚も引けない確率はおよそ55.5%**という計算になります。逆に言えば、「1枚以上引ける確率」は約44.5%です。感覚としてはかなり高い確率で事故る、というのが数字で裏付けられました。

## 採用枚数を増やすとどう変わるか

冒頭の表からも分かる通り、採用枚数を増やすほど「1枚以上引ける確率」は上がっていきますが、その伸び方は一様ではありません。**採用枚数を2枚から4枚に増やすだけで、引ける確率は25.1%から44.5%までおよそ1.8倍**になります。一方で、8枚から10枚に増やしても伸び幅（70.6%→79.0%）は小さくなっていきます。これは超幾何分布特有の「収穫逓減」の性質で、採用枚数が少ないうちは1枚増やす効果が非常に大きく、ある程度の枚数を超えると効果が緩やかになっていくということです。

デッキ構築では「このカードを1枚増やすべきか、それとも別のカードに枠を使うべきか」という判断が常に求められます。上記のような感覚を持っておくと、特に採用枚数が少ない領域（2〜4枚あたり）で1枚の増減がいかに結果を左右するかが直感的にわかるようになります。

## サーチカードがある場合はどう考える?

実際のデッキには、目当てのカードを直接引かなくても、サーチ効果を持つトレーナーズやポケモンのワザで手札に加えられる場合があります。この場合、単純な超幾何分布だけでは「実質的にそのカードにアクセスできる確率」を正確に表せません。

ただし、考え方の基本は同じです。「目当てのカードを直接引く」という当たりに加えて、「サーチ役を引いて、かつそれを使う」という別の経路も確率として合成していくイメージです。この手の複合条件の計算は手計算だとかなり煩雑になるため、実際のデッキで細かくシミュレーションしたい場合は「ポケカデッキ分析ツール」を使って、自分のデッキリストをそのまま入力し、初手や数ターン後の確率を計算してみることをおすすめします。採用枚数を1枚変えるだけで確率がどう動くかも、ツール上ならすぐに比較できます。

## まとめ

- 初手でカードを引ける確率は超幾何分布 `P(X=k) = C(K,k)×C(N-K,n-k)/C(N,n)` で計算できる
- 目当てのカードを4枚採用の場合、初手8枚で1枚も引けない確率は約55.5%と、意外に高い
- 採用枚数が少ない領域では、1枚増やすことの効果が特に大きい
- サーチカードが絡む複合的な確率計算は、ツールを使ったシミュレーションが便利

「なんとなく事故りやすい気がする」で終わらせず、実際の数字で採用枚数を検討してみると、デッキ構築の精度がぐっと上がります。ぜひ自分のデッキでも計算してみてください。
