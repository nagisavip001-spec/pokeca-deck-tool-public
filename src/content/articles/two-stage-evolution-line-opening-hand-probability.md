## はじめに

2進化ポケモンをアタッカーに据えるデッキでは、「たねポケモン」「1進化」「2進化」という3段階のカードをそれぞれデッキに採用する必要があります。理想を言えば、初手の時点でこの3枚がすべて手札に揃っていれば、あとは進化させるだけで最速で完成形のポケモンを立てられます。しかし直感的にも分かる通り、3種類のカードが同時に手札に来る確率はかなり低いはずです。

この記事では、たね・1進化・2進化の採用枚数を変えながら、「初手8枚の中に3段階すべてが1枚以上含まれている確率」を超幾何分布を使って厳密に計算し、2進化ラインを軸にしたデッキ構築でどこまで初動に期待していいのかを数字で確認します。

## 計算方法（超幾何分布と包除原理）

まず基本となる超幾何分布の式はこうでした。

```
P(X = k) = C(K, k) × C(N-K, n-k) / C(N, n)
```

- `N`：デッキの総枚数（通常60枚）
- `K`：デッキ内の目当てのカードの採用枚数
- `n`：引く枚数（この記事では初手8枚を基準にします）
- `k`：その中で目当てのカードが出た枚数

今回知りたいのは「たね・1進化・2進化の3種類が、それぞれ1枚以上含まれている確率」なので、単純な超幾何分布1本では計算できません。そこで使うのが**包除原理（inclusion-exclusion）**です。

たねの採用枚数を`a`、1進化を`b`、2進化を`c`とし、「初手8枚の中にそのカードが1枚も無い確率」をそれぞれ次のように表します。

```
P(たね無し)         = C(N-a, n) / C(N, n)
P(1進化無し)         = C(N-b, n) / C(N, n)
P(2進化無し)         = C(N-c, n) / C(N, n)
P(たね・1進化ともに無し) = C(N-a-b, n) / C(N, n)
P(たね・2進化ともに無し) = C(N-a-c, n) / C(N, n)
P(1進化・2進化ともに無し) = C(N-b-c, n) / C(N, n)
P(3種類とも無し)       = C(N-a-b-c, n) / C(N, n)
```

「3種類のうち少なくとも1種類が無い確率」は、包除原理により次の式で求まります。

```
P(いずれか欠ける) = P(たね無し) + P(1進化無し) + P(2進化無し)
                  − P(たね・1進化無し) − P(たね・2進化無し) − P(1進化・2進化無し)
                  + P(3種類とも無し)
```

最後に、求めたい「3種類すべてが1枚以上揃う確率」は、これを1から引くだけです。

```
P(3種類すべて揃う) = 1 − P(いずれか欠ける)
```

## 具体例：たね4枚・1進化4枚・2進化4枚のケース

もっとも採用枚数を厚くした「たね4枚・1進化4枚・2進化4枚」のケースで実際に計算してみます。`N=60`、`n=8`として、

```
P(たね無し)          = C(56,8)/C(60,8) ≒ 0.5552
P(1進化無し)          = C(56,8)/C(60,8) ≒ 0.5552
P(2進化無し)          = C(56,8)/C(60,8) ≒ 0.5552
P(たね・1進化ともに無し) = C(52,8)/C(60,8) ≒ 0.2941
P(たね・2進化ともに無し) = C(52,8)/C(60,8) ≒ 0.2941
P(1進化・2進化ともに無し) = C(52,8)/C(60,8) ≒ 0.2941
P(3種類とも無し)        = C(48,8)/C(60,8) ≒ 0.1475
```

これを包除原理の式に当てはめると、

```
P(いずれか欠ける) = 0.5552×3 − 0.2941×3 + 0.1475 ≒ 0.9308
P(3種類すべて揃う) = 1 − 0.9308 ≒ 0.0692（約6.9%）
```

つまり、たね・1進化・2進化をそれぞれ4枚ずつ、合計12枚もの進化ラインを採用しても、**初手8枚の時点で3段階すべてが揃っている確率はわずか約6.9%**、およそ14〜15回に1回程度しかありません。冒頭の表を見ても分かる通り、採用枚数を減らすほどこの確率はさらに厳しくなり、たね・1進化・2進化をすべて2枚採用にすると約1.1%まで下がります。

## 採用枚数を増やすとどう変わるか、実戦での考察

冒頭の表から読み取れる傾向をいくつか整理します。

- **枚数を1種類だけ増やしても伸びは限定的**：たね4枚・1進化4枚を固定し、2進化だけを1枚→4枚まで増やすと、確率は約2.0%→約3.8%→約5.4%→約6.9%と伸びていきますが、2進化を4枚も採用してようやく約6.9%です。1種類の増枚だけでは大きな改善になりにくいことが分かります。
- **3段階すべて厚めに積んで、ようやく1割未満**：もっとも枚数を積んだ4-4-4構成でも約6.9%であり、2進化ラインを初手だけで完成させることは基本的に狙って起こる現象ではありません。
- **「進化の途中まで」なら現実的な確率になる**：同じ4-4構成で、2進化を除いた「たね＋1進化の2種類が揃う確率」を計算すると約18.4%まで上がります。つまり初手時点では「1進化まで進める準備」を目標にするほうが現実的で、2進化への到達は2〜3ターン目以降のドローに委ねるのが自然な設計です。
- **ターンが進むと到達率は着実に伸びる**：たね4枚・1進化4枚・2進化4枚の構成で、見たカード枚数`n`を初手8枚から1枚ずつ増やしていくと、3種類すべてが揃う確率は次のように伸びていきます。

| 経過ターン（後攻視点） | 見たカード枚数 n | 3種類すべて揃う確率 |
|---|---|---|
| 初手（1ターン目） | 8枚 | 約6.9% |
| 2ターン目終了時 | 9枚 | 約9.6% |
| 3ターン目終了時 | 10枚 | 約12.6% |
| 4ターン目終了時 | 11枚 | 約15.9% |

このように、2進化ラインを1枚も欠かさず手札に揃える確率は、初手だけを見ると1割にも満たない厳しい数字ですが、ターンを重ねるごとに確実に伸びていきます。サーチカードやドローサポートを使えばさらに前倒しできるため、「初手で完成しなくて当然」と割り切り、たねポケモンをまず場に出すこと、1進化までを早めに進めることを優先する構築・プレイングが理にかなっていると言えます。
