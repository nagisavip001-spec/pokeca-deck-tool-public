## はじめに

これまでの確率コラムでは、「目当てのカードが初手に1枚以上来る確率」や「2枚以上握れる確率」を中心に扱ってきました。どちらも実戦でそのまま使える便利な指標ですが、どちらも「ある/ない」の二択で確率を切り出したものです。

超幾何分布にはもう一つ、別の角度から「引きの良し悪し」を捉える道具があります。それが**期待値（平均で何枚来るか）**と**分散・標準偏差（平均からどれくらいブレるか）**です。「採用8枚なら初手に平均1.1枚来る」と言われても、実際の試合では0枚のことも2枚以上のこともあり、その『ブレの大きさ』まで込みで考えないと採用枚数の判断を誤ります。この記事では、超幾何分布の期待値と分散の式を使って、初手8枚における枚数の「平均」と「ブレ」を厳密に計算し、上の表に並んでいる「0枚・1枚・2枚以上」の内訳確率とどう対応しているのかを見ていきます。

## 計算方法（超幾何分布の式）

おさらいとして、超幾何分布の基本式は以下の通りです。

```
P(X = k) = C(K, k) × C(N-K, n-k) / C(N, n)
```

- `N`：デッキの総枚数（60枚）
- `K`：対象カードの採用枚数
- `n`：引く枚数（初手8枚）
- `k`：その中で対象カードが出た枚数

この分布には、組み合わせを1つずつ数え上げなくても平均とブレを直接求められる公式があります。

```
期待値  E[X] = n × K / N
分散    Var[X] = n × (K/N) × ((N-K)/N) × ((N-n)/(N-1))
標準偏差 SD[X] = √Var[X]
```

`E[X] = n × K / N` は「デッキ全体に占める対象カードの比率（K/N）に、引く枚数nを掛けたもの」で、直感的にも分かりやすい式です。一方の分散には末尾に `(N-n)/(N-1)` という補正項が付いています。これは「カードを戻さずに引く（非復元抽出）」ことによる効果で、nがNに近づくほど（デッキを引き切るほど）ブレが小さくなることを表しています。初手8枚はデッキ60枚のうちごく一部なので、この補正項は1に近い値（今回は52/59≈0.881）になり、ブレはあまり抑え込まれません。

## 具体例：採用8枚のカードで期待値と標準偏差を計算する

ハイパーボールのような8枚前後採用するカードを例に、初手8枚（N=60、n=8、K=8）で計算してみます。

```
E[X] = 8 × 8 / 60 ≈ 1.067（約1.1枚）

Var[X] = 8 × (8/60) × (52/60) × (52/59)
       ≈ 8 × 0.1333 × 0.8667 × 0.8814
       ≈ 0.8148

SD[X] = √0.8148 ≈ 0.903（約0.9枚）
```

平均すると初手に約1.1枚来る計算ですが、標準偏差は約0.9枚もあり、平均とほぼ同じ大きさのブレが存在します。実際の内訳を見ると、上の表の通り「0枚」が約29.4%、「1枚」が約41.8%、「2枚以上」が約28.8%です。「平均1.1枚だからだいたい1枚は来るだろう」という感覚とは裏腹に、約3割はまったく引けておらず、約3割は2枚以上抱えている計算になります。平均値ひとつだけでは、この「山なりに広がった分布」の実態は見えてきません。

## 採用枚数を増やすとどう変わるか

採用枚数Kを変えながら、期待値E[X]と標準偏差SD[X]を比較すると次のようになります（N=60、n=8固定）。

| 採用枚数 | 期待値（平均枚数） | 標準偏差（ブレの大きさ） |
|---|---|---|
| 1枚 | 約0.1枚 | 約0.3枚 |
| 2枚 | 約0.3枚 | 約0.5枚 |
| 4枚 | 約0.5枚 | 約0.7枚 |
| 6枚 | 約0.8枚 | 約0.8枚 |
| 8枚 | 約1.1枚 | 約0.9枚 |
| 10枚 | 約1.3枚 | 約1.0枚 |
| 12枚 | 約1.6枚 | 約1.1枚 |
| 16枚 | 約2.1枚 | 約1.2枚 |
| 20枚 | 約2.7枚 | 約1.3枚 |

期待値E[X]は採用枚数にきれいに比例して伸びていきますが、標準偏差SD[X]の伸びはそれよりずっと緩やかです。採用枚数を1枚→20枚と20倍に増やしても、標準偏差は約0.3枚→約1.3枚と4倍程度にしか増えません。これは標準偏差が`K×(N-K)`という、Kが小さいうちもNに近づいても小さくなる形の関数に比例しているためで、中間的な採用枚数（今回のデータでは12〜16枚あたり）でブレが最も大きくなります。

実戦的に言い換えると、**採用枚数が少ないカードは「平均より増えすぎる」心配はほぼ無い一方、採用枚数を増やしていくと「平均から大きく外れて0枚だけ来る」リスクも「2枚以上抱えて持て余す」リスクも両方じわじわ大きくなっていく**ということです。上の表で言えば、8枚採用あたりから「0枚（約29.4%）」と「2枚以上（約28.8%）」がほぼ同じ比率で並び立ち、「平均どおり1枚」が主役ではなくなってくる点が読み取れます。終盤まで温存したいサポートのように「2枚以上は持て余す」カードを厚く採用するときは、平均値の伸びだけでなく、このブレの大きさも合わせて確認しておくと、採用枚数の落としどころを数字で判断しやすくなります。

## まとめ

- 超幾何分布には`E[X] = n×K/N`という期待値の式があり、初手に対象カードが平均何枚来るかを直接計算できる
- 分散は`Var[X] = n×(K/N)×((N-K)/N)×((N-n)/(N-1))`で求められ、末尾の`(N-n)/(N-1)`は非復元抽出によるブレの補正項
- 期待値だけを見ると分からない「0枚（外れ）」や「2枚以上（当たり過ぎ）」の確率は、標準偏差と組み合わせて見ることで、分布の広がりとして具体的に把握できる
- 標準偏差の伸びは期待値の伸びよりずっと緩やかなため、採用枚数を増やすほど「平均からのブレ」の比重が相対的に大きくなっていく

「平均で何枚来るか」という一点だけで採用枚数を決めるのではなく、その周りにどれくらいの幅でブレているかまで含めて考えると、「1枚以上来る確率」や「2枚以上握れる確率」といった個別の指標の意味もより立体的に理解できるようになります。気になる採用枚数があれば、ぜひ「ポケカデッキ分析ツール」で実際の数値を確認してみてください。
