## はじめに

ポケモンカードには、「2枚のカードが揃って初めて機能する」コンボがたくさんあります。

- 「ふしぎなアメ」と、そのアメで進化させたい3進化ポケモン
- 特定のワザを使うポケモンと、それを支えるサポート
- 山札を掘るためのグッズと、その効果を活かすポケモン

こうしたコンボを初手（8枚）で同時に引けるかどうかは、デッキ選定において非常に重要な情報です。しかし「Aだけを引ける確率」や「Bだけを引ける確率」は計算できても、「AとBを両方とも引ける確率」となると、少し計算が複雑になります。この記事では、以前の記事で紹介した超幾何分布の考え方を拡張して、2種類のカードを同時に引ける確率を求める方法を解説します。

## おさらい：超幾何分布の基本式

超幾何分布は、デッキ（母集団）から一定枚数を引いたときに、特定のカードが何枚含まれるかを表す確率分布でした。

```
P(X = k) = C(K, k) × C(N-K, n-k) / C(N, n)
```

- `N`：デッキの総枚数（通常60枚）
- `K`：当たりカードの枚数
- `n`：引く枚数（初手なら8枚）
- `k`：当たりが出てほしい枚数
- `C(a, b)`：a枚からb枚を選ぶ組み合わせの数

特に「1枚も引けない確率」`P(X = 0)` は `C(N-K, n) / C(N, n)` というシンプルな形になるのがポイントです。当たり以外のカード（N-K枚）だけからn枚を選ぶ場合の数を、全体からn枚を選ぶ場合の数で割ればよいからです。この記事では、この「1枚も引けない確率」を土台にして、2種類のカードの同時ヒット確率を組み立てていきます。

## 2種類のカードを両方引ける確率の求め方

カードAをK<sub>A</sub>枚、カードBをK<sub>B</sub>枚採用しているデッキがあるとします（AとBは別のカードで、重複はしないものとします）。初手n枚の中に、AとBが**両方とも1枚以上**含まれる確率を求めたいとします。

ここで便利なのが、確率の余事象・包除原理という考え方です。「AもBも1枚以上引ける」の否定は、「Aが0枚、またはBが0枚」なので、次のように分解できます。

```
P(A≥1 かつ B≥1) = 1 − P(A=0) − P(B=0) + P(A=0 かつ B=0)
```

最後の項を足し戻しているのは、「Aが0枚」と「Bが0枚」の両方に「AもBも0枚」のケースが二重に引かれてしまうためです（ベン図を思い浮かべると分かりやすいでしょう）。

それぞれの項は、先ほどの「1枚も引けない確率」の式がそのまま使えます。

```
P(A=0)        = C(N−K_A, n) / C(N, n)
P(B=0)        = C(N−K_B, n) / C(N, n)
P(A=0 かつ B=0) = C(N−K_A−K_B, n) / C(N, n)
```

3つ目の式は、「AでもBでもないカード」が `N − K_A − K_B` 枚あるので、そこからn枚を選ぶ場合の数を考えればよい、という発想です。これは超幾何分布の当たり枚数を「AまたはB」という1つのグループにまとめて `K = K_A + K_B` としたときの `P(X=0)` と同じ計算になっています。

## 具体例：ふしぎなアメ4枚＋進化先ポケモン3枚

実際に数字を当てはめてみましょう。次のようなデッキを考えます。

- デッキ枚数 `N = 60`
- 「ふしぎなアメ」の採用枚数 `K_A = 4`
- 進化先の3進化ポケモンの採用枚数 `K_B = 3`
- 初手の枚数 `n = 8`

まず、それぞれ単独で0枚の確率を計算します。

```
P(A=0) = C(56, 8) / C(60, 8) ≒ 0.5552（約55.5%）
P(B=0) = C(57, 8) / C(60, 8) ≒ 0.6458（約64.6%）
```

次に、両方とも0枚（AでもBでもないカード53枚からのみ8枚を引く）確率を求めます。

```
P(A=0 かつ B=0) = C(53, 8) / C(60, 8) ≒ 0.3464（約34.6%）
```

これらを先ほどの式に当てはめると、

```
P(A≥1 かつ B≥1) = 1 − 0.5552 − 0.6458 + 0.3464 ≒ 0.1454
```

つまり、初手8枚でふしぎなアメと進化先のポケモンを**両方とも引ける確率は約14.5%**しかありません。単独で見ると、アメを1枚以上引ける確率は約44.5%、進化先を1枚以上引ける確率は約35.4%とそこまで低くないのに、両方揃うとなると一気に確率が下がってしまうのが分かります。これがいわゆる「コンボデッキの初動事故」の正体です。

## 採用枚数を増やすとどう変わるか

では、進化先のポケモンを3枚から4枚に増やすとどうなるでしょうか。同じ計算をK<sub>B</sub>=4で行うと、

```
P(A≥1 かつ B≥1) ≒ 0.1838（約18.4%）
```

わずか1枚増やしただけで、同時ヒット率が約14.5%から約18.4%へと4ポイント近く上昇します。逆に、アメを3枚に減らしてK<sub>A</sub>=3、K<sub>B</sub>=3にすると、

```
P(A≥1 かつ B≥1) ≒ 0.1150（約11.5%）
```

まで下がってしまいます。このように、2種類のカードを組み合わせて使う戦略では、採用枚数の1枚の増減が、単独のカードで考える以上に大きく結果に影響することが分かります。「アメが4枚あるから安心」ではなく、「進化先を何枚積むか」も同じくらい重要な判断材料になるわけです。

## まとめ

- 2種類のカードを両方とも初手で引きたい場合は、単純に個別の確率を掛け算するのではなく、`1 − P(A=0) − P(B=0) + P(A=0かつB=0)` という包除原理の考え方で計算する
- それぞれの項は超幾何分布の `P(X=0) = C(N-K, n) / C(N, n)` の形で求められる
- コンボの成立確率は、単独のカードを引ける確率よりもかなり低くなりやすい
- 採用枚数を1枚変えるだけでも、コンボの成立確率には無視できない影響が出る

こうした計算は手作業だと大変ですが、「ポケカデッキ分析ツール」を使えば、採用枚数を入力するだけで初手8枚におけるコンボ成立確率をすぐに確認できます。気になるデッキのキーカードの組み合わせを、ぜひ一度シミュレーションしてみてください。
