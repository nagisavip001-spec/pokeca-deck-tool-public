## はじめに

「目当てのポケモンが1〜2枚しか採用できない」というのは、デッキ構築でよくある悩みです。1進化先が1枚しかいない、特定のアタッカーが1枚だけの構築、といった場面では、初手にそのカードが直接来る確率はどうしても低くなります。

そこで頼りになるのが「ネストボール」のような、たねポケモンを山札から直接ベンチに出せるサーチカードです。初手にサーチカードさえあれば、目当てのポケモン自身が初手に来ていなくても、山札から確実に呼び出すことができます。つまり、目当てのポケモンへの「実質的な到達率」は、そのポケモン自身の採用枚数だけでなく、サーチカードの採用枚数にも左右されるということです。

この記事では、「初手8枚の中に、目当てのポケモンかサーチカードのどちらかが1枚以上含まれる確率」を超幾何分布で計算し、サーチカードを増やすことがどれだけ到達率を押し上げるのかを具体的な数字で確認します。

## 計算方法（超幾何分布の式）

超幾何分布の基本式はこうでした。

```
P(X = k) = C(K, k) × C(N-K, n-k) / C(N, n)
```

- `N`：デッキの総枚数（通常60枚）
- `K`：対象カードの採用枚数
- `n`：引く枚数（初手8枚）
- `k`：その中に対象カードが含まれる枚数

ここで考えたいのは、「目当てのポケモン（K<sub>t</sub>枚）」と「サーチカード（K<sub>s</sub>枚）」という2種類のカードのうち、どちらか一方でも初手に来ていれば「実質的に到達できた」とみなせる確率です。ネストボールのようなサーチカードは、探す時点で目当てのポケモンが山札に残っていれば確実に見つけられるため、「目当てのポケモンが初手に0枚、かつサーチカードも初手に0枚」の場合にのみ、実質的な到達に失敗すると考えられます。

この「両方とも0枚」になる確率は、目当てのポケモンでもサーチカードでもない残り `N-K_t-K_s` 枚の中だけからn枚を選ぶ場合の数を、デッキ全体からn枚を選ぶ場合の数で割った形になります。

```
P(到達失敗) = C(N-K_t-K_s, n) / C(N, n)
P(実質到達) = 1 − C(N-K_t-K_s, n) / C(N, n)
```

この式のポイントは、`K_t` と `K_s` が式の中で**足し算の形（K_t + K_s）でしか登場しない**ことです。つまり計算上は、サーチカードを1枚増やすことは、目当てのポケモンそのものを1枚増やすことと、実質到達率の観点ではまったく同じ効果を持ちます。

## 具体例

目当てのポケモンを**1枚**しか採用できないデッキで、ネストボールを**4枚**採用した場合を計算してみます。

- `N = 60`
- `K_t = 1`、`K_s = 4`（合計5枚扱い）
- `n = 8`

```
P(到達失敗) = C(55, 8) / C(60, 8) ≒ 0.476
P(実質到達) = 1 − 0.476 ≒ 0.524（約52.4%）
```

目当てのポケモン自身を初手で直接引ける確率は約13.3%しかありませんが、ネストボール4枚をあわせて考えると、実質的な到達率は約52.4%まで上がります。これは、目当てのポケモンを1枚のままサーチカードなしで5枚採用した場合（K=5の直接ヒット率）とちょうど同じ数字です。1枚しか積めない貴重なカードでも、サーチカードの採用枚数次第で「ほぼ5枚採用しているのと同じ安定感」を作れるということが、この計算から分かります。

## 採用枚数を増やすとどう変わるか、または実戦での考察

冒頭の表を見ると、サーチカード0枚→4枚への変化幅は、目当てのポケモンの採用枚数によって異なることが分かります。

- 目当てのポケモン1枚のとき：約13.3%→約52.4%（**+39.1pt**）
- 目当てのポケモン2枚のとき：約25.1%→約59.3%（**+34.2pt**）
- 目当てのポケモン4枚のとき：約44.5%→約70.6%（**+26.1pt**）

目当てのポケモンの採用枚数が少ないカードほど、サーチカードを増やしたときの伸び幅が大きくなります。裏を返せば、すでに4枚フル投入しているカードにサーチカードを足しても、伸び幅は相対的に小さくなるということです。「1枚しか採用できない貴重なアタッカー」や「1進化先が1種類しかいないポケモン」ほど、サーチカードの恩恵を強く受けやすいと言えます。

また、計算上は「サーチカード＝目当てのカードと同じ1枚」として扱えますが、実戦ではサーチカードにしかない利点もあります。ネストボールは対象を「たねポケモン」全般から選べるため、デッキに複数種類のたねポケモンがいる場合、そのとき本当に必要な1種類を状況に応じて呼び出せます。目当てのポケモン自体を追加で採用するのと違い、サーチカード1枚は複数の異なるカードに対する保険として働く柔軟性を持っている点は、単純な到達率の数字には表れない追加のメリットです。

一方で、この計算はサーチカードが確実に成功する（山札に対象が残っていれば必ず見つかる）ことを前提にしています。ハイパーボールのように手札を2枚捨てるコストがあるカードや、進化ポケモンを探せないカードなど、実際の効果テキストによって条件は変わるため、採用するサーチカードの効果は必ず確認しておきましょう。

## まとめ

- 目当てのポケモンとサーチカードのどちらかが初手にあれば到達できる確率は、`P(実質到達) = 1 − C(N-K_t-K_s, n) / C(N, n)` で計算できる
- 式の上では、サーチカード1枚は目当てのポケモン1枚を追加するのとほぼ同じ効果を持つ
- 採用枚数が少ないカードほど、サーチカードを増やしたときの到達率の伸び幅が大きい
- サーチカードは複数の異なるカードへの保険にもなるため、単純な到達率以上の柔軟性がある

「1枚しか採用できないカードが不安」というときは、そのカード自体の増枠だけでなく、サーチカードの採用枚数を見直すことでも実質的な安定感を高められます。自分のデッキ構成でどれくらい変わるか気になる方は、「ポケカデッキ分析ツール」で実際の枚数を入力して確認してみてください。
