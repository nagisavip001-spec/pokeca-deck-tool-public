|---|---|---|
| 6枚 | 6枚 | 約39.4% |
| 5枚 | 5枚 | 約33.8% |

| 3枚 | 3枚 | 約21.4% |
| 2枚 | 2枚 | 約14.6% |
| 1枚 | 1枚 | 約7.5% |

（条件：ナンジャモを使う時点で山札残り40枚、目当てのカードが山札に3枚残っている状態を想定）

## はじめに

「リーリエの決心」「博士の研究」「ゼイユ」など、手札を引き直すサポートには様々な種類がありますが、その多くは引き直す枚数が固定（7枚や5枚など）です。一方で「ナンジャモ」は少し特殊で、**お互いのプレイヤーが自分の残りサイド枚数と同じ枚数だけ手札を引き直す**という効果を持っています（サイドが0枚の場合は4枚引く特別ルールがありますが、通常は最後のサイドを取った瞬間に勝利するため、対戦中に自分の残りサイドが0枚の状態でナンジャモを使う場面はほぼ発生しません）。

つまりナンジャモを使ったときに目当てのカードを引ける確率は、**対戦の序盤か終盤かによって大きく変わる**ということです。サイドをたくさん取った終盤ほど引き直せる枚数が減っていくため、「勝利まであと少し」という場面ほど、実は目当てのカードを引きにくくなるというジレンマがあります。この記事では、サイド残り枚数ごとにナンジャモで目当てのカードを引ける確率を超幾何分布で厳密に計算し、採用枚数を増やした場合にこのジレンマがどこまで緩和されるかを確認します。

## 計算方法（超幾何分布の式）

ナンジャモを使うと、自分の手札は一旦すべて山札に戻されてシャッフルされます。そのため、引き直した手札に目当てのカードが1枚以上含まれる確率は、その時点の山札残り枚数を母数とした超幾何分布で計算できます。

```
P(X ≥ 1) = 1 − C(N−K, n) / C(N, n)
```

- `N`：ナンジャモを使う時点での山札の残り枚数（手札をシャッフルで戻した後の枚数）
- `K`：目当てのカードのうち、山札に残っている枚数（手札や捨札にあるものは含まない）
- `n`：引き直す枚数＝そのときの自分の残りサイド枚数（0枚の場合のみ4枚）

ポイントは `n` が試合の進行状況によって変化する変数だということです。序盤にサイドを1枚も取っていなければ `n = 6` ですが、あと1枚でゲームが終わる終盤には `n = 1` まで小さくなります。母数となる `N` や `K` が同じでも、`n` の違いだけで到達率は大きく変わります。

## 具体例：山札残り40枚・目当てのカード3枚・サイド残り4枚の場合

冒頭の表の「サイド残り4枚」の行を実際に計算してみます。

- `N = 40`、`K = 3`、`n = 4`
- `C(40, 4) = 91,390`
- `C(37, 4) = 66,045`（目当てのカードが1枚も来ない組み合わせの数）

```
P(X = 0) = C(37, 4) / C(40, 4) ≒ 0.72267（約72.3%）
P(X ≥ 1) = 1 − 0.72267 ≒ 0.27733（約27.7%）
```

サイドを2枚取った段階（残り4枚）でナンジャモを使うと、目当てのカードが1枚以上来る確率は約27.7%です。これが冒頭の表の該当行と一致します。同じ条件のまま `n` を1〜6の間で動かすと、冒頭の表の通り約7.5%〜約39.4%まで変動することが分かります。

## 採用枚数を増やすとどう変わるか

「終盤ほど引きにくくなる」ジレンマを、採用枚数を増やすことでどこまで補えるか確認します。山札残り40枚・サイド残り3枚（引き直し3枚）で固定し、目当てのカードの採用枚数（＝山札に残っている枚数）だけを変えた場合の確率です。

| 採用枚数（山札に残っている枚数） | サイド残り3枚のときの到達率 |
|---|---|
| 1枚 | 約7.5% |
| 2枚 | 約14.6% |
| 3枚 | 約21.4% |
| 4枚 | 約27.7% |

さらに、「序盤（サイド残り6枚）」と「終盤（サイド残り1枚）」で採用枚数ごとの到達率を比べると、その差の大きさがよく分かります。

| 採用枚数 | サイド残り6枚（序盤） | サイド残り1枚（終盤） |
|---|---|---|
| 2枚 | 約28.1% | 約5.0% |
| 3枚 | 約39.4% | 約7.5% |
| 4枚 | 約49.3% | 約10.0% |

採用枚数を1枚から4枚に増やしても、終盤（サイド残り1枚）の到達率は約7.5%→約10.0%までしか改善しません。これは `n = 1` の場合、到達率がほぼ `K / N` に近似され、母数となる `N`（山札残り枚数）が大きいままだと採用枚数を増やす効果が薄いためです。一方で序盤（サイド残り6枚）は同じ採用枚数の変化で約28.1%→約49.3%まで大きく伸びています。

つまり、**ナンジャモを終盤の「詰め」の引き直しとして頼りにする場合、採用枚数を増やすだけでは限界がある**ということです。終盤にナンジャモで目当てのカードを引き当てたいなら、採用枚数を増やす以上に、サーチカードで先に山札の中の目当てのカードの割合（K/N比）自体を高めておく、あるいはナンジャモに頼らず先に手札に抱えておく立ち回りが実戦的な対策になります。逆に序盤〜中盤にナンジャモを使う場合は、採用枚数を増やす恩恵をそのまま受けやすいため、「いつナンジャモを使うか」というタイミングの判断材料としてもこの表を活用できます。

## まとめ

- ナンジャモは残りサイド枚数と同じ枚数だけ手札を引き直すため、引き直す枚数 `n` は試合の進行によって変化する
- 山札残り40枚・目当てのカード3枚の条件では、サイド残り6枚（約39.4%）からサイド残り1枚（約7.5%）まで到達率が大きく下がる
- 終盤（サイド残り1枚）は引き直す枚数自体が少ないため、採用枚数を増やしても到達率の伸びは小さい（約7.5%→約10.0%）
- 序盤〜中盤にナンジャモを使う場合は、採用枚数を増やす効果をより大きく受けられる
- 終盤の「詰め」でナンジャモに頼るなら、採用枚数の増加よりもサーチカードでの事前の割合改善や、先に手札へ抱えておく立ち回りが有効

サイド残り枚数によって引き直せる枚数が変わるナンジャモは、単純な引き直しサポートと違って「いつ使うか」自体が到達率を左右します。試合の進行度に応じた到達率の目安を持っておくと、ナンジャモを切るタイミングの判断材料になります。
