## はじめに

以前の記事で、「たね」「1進化」「2進化」の3種類全てが**初手8枚**に同時に揃う確率を計算しました。4-4-4という厚めの構成でも約6.9%しかなく、初手だけで2進化ラインが完成する試合はごく稀という結論でした。

では、初手で揃わなかった場合、実際には**何ターン目くらいまで待てば、2進化ラインが完成している見込みが立つ**のでしょうか。ポケカは「初手で揃わなければ終わり」のゲームではなく、ターンを重ねてドローを続けられます。この記事では、以前扱った「2種類のカードを同時に引ける確率（包除原理）」と「何ターン目までに引けるか（累積ドロー）」という2つの考え方を組み合わせて、2進化ラインが完成するまでの累積確率がターンを追うごとにどう伸びていくのかを計算します。

## 計算方法（超幾何分布の式）

土台になるのは、これまでと同じ超幾何分布です。

```
P(X = k) = C(K, k) × C(N-K, n-k) / C(N, n)
```

- `N`：デッキの総枚数（通常60枚）
- `K`：対象カードの採用枚数
- `n`：これまでに見たカードの枚数
- `k`：その中に対象カードが含まれる枚数

3種類のカード（たねA、1進化B、2進化C）が**全て1枚以上**見えている確率を求めるには、以前紹介した包除原理を3つの集合に拡張します。「A・B・Cのどれかが0枚」を除外していく形です。

```
P(A≥1 かつ B≥1 かつ C≥1)
  = 1 − P(A=0) − P(B=0) − P(C=0)
    + P(A=0,B=0) + P(A=0,C=0) + P(B=0,C=0)
    − P(A=0,B=0,C=0)
```

それぞれの項は、超幾何分布の「1枚も引けない確率」`P(X=0) = C(N−K, n) / C(N, n)` の形で計算できます。2枚以上のグループが同時に0枚になる確率は、そのグループの採用枚数を合計した `K` を使えば同じ式に当てはめられます。たとえば「AとBが両方とも0枚」なら `K = K_A + K_B` として `C(N−K_A−K_B, n) / C(N, n)` を計算します。

ここに、以前の記事で扱った「ターンが進むごとに n が1枚ずつ増える」という考え方を重ねます。後攻視点では、1ターン目終了時点で n=8、2ターン目終了時点で n=9、3ターン目終了時点で n=10……というように増えていくので、この n を式に代入していけば、「何ターン目終了時点で3種類全てが揃っている確率」を求められます。

## 具体例：たね4枚・1進化4枚・2進化4枚の構成

たね(A)・1進化(B)・2進化(C)をそれぞれ4枚ずつ採用した「4-4-4」構成を例に、5ターン目終了時点（n=12）での計算過程を見てみましょう。

```
P(A=0) = P(B=0) = P(C=0) = C(56, 12) / C(60, 12) ≒ 0.399（約39.9%）
P(A=0,B=0) = P(A=0,C=0) = P(B=0,C=0) = C(52, 12) / C(60, 12) ≒ 0.147（約14.7%）
P(A=0,B=0,C=0) = C(48, 12) / C(60, 12) ≒ 0.050（約5.0%）
```

これらを式に当てはめると、

```
P(全て揃う) = 1 − 3×0.399 + 3×0.147 − 0.050 ≒ 0.196（約19.6%）
```

初手（1ターン目終了、n=8）では約6.9%しかなかった到達率が、5ターン目終了時点では約19.6%まで伸びています。それでも8割は「まだ揃っていない」計算になり、2進化ラインを軸にした試合運びが、序盤の数ターンではかなり不安定になりやすいことが数字からも裏付けられます。

## 採用枚数を増やすとどう変わるか

同じ計算を、採用枚数の組み合わせを変えて比較してみます（5ターン目終了・n=12、8ターン目終了・n=15、13ターン目終了・n=20の3時点）。

| 採用枚数（たね-1進化-2進化） | 5ターン目終了(n=12) | 8ターン目終了(n=15) | 13ターン目終了(n=20) |
|---|---|---|---|
| 4-4-4 | 約19.6% | 約31.6% | 約52.4% |
| 4-4-3 | 約15.9% | 約26.4% | 約45.6% |
| 4-3-3 | 約13.0% | 約22.0% | 約39.7% |
| 3-3-3 | 約10.6% | 約18.4% | 約34.5% |

最も厚い4-4-4構成でも、13ターン目終了時点（n=20、後攻でおよそ試合中盤〜終盤にあたる枚数）でようやく約52.4%と五分五分に届く水準です。3-3-3まで枚数を絞ると、同じ時点でも約34.5%にとどまります。3枚から4枚に増やすという「たった1枚の差」が、ターンを重ねた累積確率でも一貫して5〜8ポイント前後の差になって現れ続けることが分かります。

この結果は実戦的にも重要な示唆を持っています。2進化ポケモンをアタッカーの主軸に据えるデッキでは、「初手で揃わなくても、そのうち揃うだろう」という感覚に頼ると、想定より長い間2進化が完成しないまま試合が進むリスクを見落としがちです。ふしぎなアメで1進化を飛ばしたり、ボールカードで1進化・2進化そのものをサーチしたりする手段を用意しておくと、この累積確率の伸びをさらに前倒しにできます（サーチカードによる実質到達率の伸ばし方は別の記事で扱っているので、あわせて確認してみてください）。逆に言えば、そうしたサポート手段を持たないデッキほど、今回の表よりもさらに厳しい前提で試合運びを組み立てる必要があります。

## まとめ

- 3種類のカードが全て揃う確率は、超幾何分布の `P(X=0)` を3つの集合の包除原理で組み合わせることで計算できる
- ターンが進むごとに「見たカードの枚数」nが増えていく累積ドローの考え方と組み合わせると、「何ターン目までに揃うか」を数値化できる
- 4-4-4構成でも、13ターン目終了時点でようやく五分五分（約52.4%）に届く水準で、2進化ラインの完成は決して早くない
- 採用枚数を1枚増やす効果は、初手だけでなくターンを重ねた累積確率でも一貫して効いてくる

2進化を軸にしたデッキを組む際は、初手到達率だけでなく「何ターン目までにどれくらいの見込みがあるか」という累積の視点も持っておくと、サーチカードの必要枚数やマリガン許容ラインの判断がより現実的になります。ぜひ「ポケカデッキ分析ツール」で自分のデッキの採用枚数を入力し、実際の伸び方を確認してみてください。
