## はじめに

ポケモンカードのマリガンについては「初手7枚にたねポケモンが1枚もない確率」を扱った記事は多くありますが、実戦で本当に怖いのは1回のマリガンそのものよりも、**マリガンが2回・3回と連続してしまうケース**です。マリガンを繰り返すたびに相手は追加でカードを引ける権利を得ていくため、連続マリガンは1回のマリガンよりもはるかに大きな不利につながります。

公式ルールでは、マリガンをすると手札を相手に見せてから山札に戻してシャッフルし、7枚を引き直します。そして対戦開始前に、相手は自分がマリガンした回数と同じ枚数まで、山札から追加でカードを引くかどうかを任意で選べます（引かなくてもよい代わりに、対戦が始まってからは引けません）。つまり、マリガンが連続する確率と、その結果として相手が得られる追加ドロー枚数の「期待値」を知っておくことは、たねポケモンの採用枚数を決める上で実戦的な意味を持ちます。

この記事では、たねポケモンの採用枚数ごとに、マリガンが連続する確率と、マリガン回数の期待値（＝相手が得られる追加ドロー枚数の期待値）を超幾何分布と幾何分布を組み合わせて厳密に計算します。

## 計算方法（超幾何分布と幾何分布の式）

まず、1回のマリガン判定でたねポケモンが1枚も来ない確率 `p` は、超幾何分布の `k = 0` のケースとして求められます。

```
p = P(X = 0) = C(N-K, n) / C(N, n)
```

- `N`：デッキの総枚数（60枚）
- `K`：デッキ内のたねポケモンの採用枚数
- `n`：引く枚数（マリガン判定は7枚）

ポイントは、マリガンをした場合に手札を**山札へ戻してシャッフルしてから引き直す**という点です。デッキの中身（たねポケモンの枚数）は変わらないため、2回目・3回目のマリガン判定も1回目とまったく同じ確率 `p` の独立試行になります。したがって、マリガンが `n` 回連続する確率は、単純に `p` の累乗で求められます。

```
P(n回連続でマリガン) = p^n
```

さらに、初手が決まるまでに平均して何回マリガンするか（＝相手が得られる追加ドロー枚数の期待値）は、幾何分布の期待値の公式から求められます。「成功（たねポケモンが来る）」の確率を `q = 1 - p` とすると、成功するまでの失敗回数（＝マリガン回数）の期待値 `E` は次の式で計算できます。

```
E = p / (1 - p) = p / q
```

## 具体例：たねポケモン8枚採用の場合

実際に数字を当てはめてみます。たねポケモンを**8枚**採用しているデッキで計算します。

- `N = 60`、`K = 8`、`n = 7`
- `C(52, 7) = 133,784,560`、`C(60, 7) = 386,206,920`

```
p = C(52, 7) / C(60, 7) ≒ 0.34641（約34.6%）
p^2 ≒ 0.11999（約12.0%）……2回連続でマリガンする確率
p^3 ≒ 0.04157（約4.2%）……3回連続でマリガンする確率
E = p / (1 - p) ≒ 0.34641 / 0.65359 ≒ 0.53000（約0.53回）
```

たねポケモン8枚採用のデッキでも、約8回に1回（12.0%）は2連続マリガンが起こる計算です。2連続マリガンになると、相手は最大2枚まで追加でカードを引ける権利を得るため、単純な1回のマリガン（34.6%）だけを見ているとこのリスクを見落としがちです。また、平均マリガン回数（期待値）は約0.53回で、これは「相手が平均してどれくらいの追加ドロー枚数の権利を得るか」の目安にもなります。

## 採用枚数を増やすとどう変わるか

冒頭の表を見ると、採用枚数が少ない領域ほど連続マリガンの確率が急激に高いことが分かります。たねポケモンが1枚しかない場合、2連続マリガンの確率は約78.0%にも達し、3連続すら約68.9%と高い水準です。これはたねポケモン1枚のデッキ自体が現実的でないことを裏付ける数字でもあります。

一方、8枚から12枚に増やすと、1回のマリガン確率は34.6%→19.1%とゆるやかにしか下がりませんが、2連続マリガンの確率は12.0%→3.6%と3倍以上、3連続マリガンの確率は4.2%→0.7%と6倍近く下がっています。これは `p` の累乗で効いてくる性質上、`p` 自体の小さな低下が連続マリガンの確率には大きな改善として跳ね返るためです。言い換えると、**「連続マリガン耐性」は、1回のマリガン率が示す以上に、たねポケモンの採用枚数を増やす恩恵が大きい**ということになります。

期待値（平均マリガン回数）の列も参考になります。8枚採用では平均0.53回、12枚採用では平均0.24回と、採用枚数を増やすほど相手に与える追加ドロー枚数の「見込み」が着実に下がっていきます。ただし期待値はあくまで平均であり、実際には0回で済むことも、2回・3回連続することもある点には注意してください。「平均は低いが、まれに大きく事故る」性質を持つのが幾何分布の特徴です。

たねポケモンを複数種採用しているデッキ（1進化ラインを複数持つデッキなど）では、たねポケモンの合計枚数がそのまま `K` になるため、この表をそのまま目安として使えます。マリガン率だけでなく連続マリガンの確率まで意識しておくと、「事故った時にどれだけ相手を有利にしてしまうか」という視点でたねポケモンの採用枚数を検討できます。

## まとめ

- マリガンを繰り返しても、たねポケモンの枚数が変わらないため各回は独立した同じ確率 `p` の試行になる
- `n` 回連続でマリガンする確率は `p^n`、平均マリガン回数（相手の追加ドロー期待値）は `p / (1 - p)` で計算できる
- たねポケモン8枚採用でも、2連続マリガンは約12.0%（8回に1回程度）起こりうる
- 採用枚数を増やすと、1回のマリガン率以上に連続マリガンの確率は大きく改善する
- 平均マリガン回数はあくまで期待値であり、実際にはばらつきがあることも踏まえて採用枚数を検討したい

1回のマリガン確率だけでなく、連続マリガンのリスクや相手に与える追加ドロー枚数の見込みまで踏まえると、たねポケモンの採用枚数の判断材料がより具体的になります。
