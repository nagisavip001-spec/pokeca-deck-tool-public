## はじめに

「たねポケモンが初手に来る確率」「エネルギーが初手に来る確率」「サーチ札が初手に来る確率」は、それぞれ単独でならこのサイトの他の記事でも扱ってきました。また、2種類のカードが同時にそろう確率（グッズ＋サポートのコンボなど）も別記事で計算しています。

しかし実戦で本当に欲しい「理想の初手」は、たいてい2条件では済みません。たとえば「①たねポケモンが場に出せる」「②そのポケモンを動かすエネルギーがある」「③展開を助けるハイパーボールやネストボールなどのサーチ札もある」の3つが同時にそろって、ようやく1ターン目から理想的に動き出せる、という状況は多くのプレイヤーが実感していることでしょう。

この記事では、この「3条件同時成立」の確率を、超幾何分布と包除原理（inclusion-exclusion）を3つの条件に拡張した形で厳密に計算します。

## 計算方法：超幾何分布と3条件への包除原理の拡張

まず基本となる超幾何分布の式はこうでした。

```
P(X = k) = C(K, k) × C(N-K, n-k) / C(N, n)
```

ある1種類のカード群（サイズK）が初手n枚に1枚も来ない確率は、k=0のケースとして

```
P(X = 0) = C(N-K, n) / C(N, n)
```

で計算できます。ここで重要なのは、「たねポケモン」「エネルギー」「キートレーナーズ」という3つのカード群をそれぞれ重複なく独立した集合として扱うと、「ある集合群がまとめて1枚も来ない確率」も同じ式で計算できることです。複数の集合（サイズの合計がSのグループ）が初手にまったく来ない確率は

```
P(そのグループが0枚) = C(N-S, n) / C(N, n)
```

となります。これを使うと、「たねポケモン(B)・エネルギー(E)・キートレーナーズ(T)の3つすべてが1枚以上来る確率」は、ド・モルガンの法則と包除原理により次の式で求められます。

```
P(B≥1 ∩ E≥1 ∩ T≥1)
  = 1 − [ P(B=0) + P(E=0) + P(T=0)
        − P(B=0,E=0) − P(B=0,T=0) − P(E=0,T=0)
        + P(B=0,E=0,T=0) ]
```

右辺の各項はすべて、該当する集合の「合計枚数」をKの代わりに使った `C(N-K, n) / C(N, n)` で計算できます。2条件の包除原理（グッズ＋サポートのコンボ記事で使用）を、3条件にそのまま拡張した形です。

## 具体例：たねポケモン8枚・エネルギー10枚・キートレーナーズ4枚のケース

実際に数字を当てはめてみます。N=60、n=8（初手8枚）、たねポケモンK_B=8枚、エネルギーK_E=10枚、キートレーナーズ（ハイパーボールなど）K_T=4枚とします。

まず各グループが単独で0枚になる確率です。

```
P(B=0) = C(52,8)/C(60,8) ≒ 0.2941
P(E=0) = C(50,8)/C(60,8) ≒ 0.2098
P(T=0) = C(56,8)/C(60,8) ≒ 0.5552
```

次に2グループがまとめて0枚になる確率（合計枚数を引いて計算）です。

```
P(B=0,E=0) = C(42,8)/C(60,8) ≒ 0.0461   （B+E=18枚を除外）
P(B=0,T=0) = C(48,8)/C(60,8) ≒ 0.1475   （B+T=12枚を除外）
P(E=0,T=0) = C(46,8)/C(60,8) ≒ 0.1020   （E+T=14枚を除外）
```

最後に3グループすべてが0枚になる確率です。

```
P(B=0,E=0,T=0) = C(38,8)/C(60,8) ≒ 0.0191   （B+E+T=22枚を除外）
```

これらを包除原理の式に当てはめると、

```
P(いずれか0枚) = 0.2941+0.2098+0.5552 − 0.0461−0.1475−0.1020 + 0.0191 ≒ 0.7826
P(3条件すべて1枚以上) = 1 − 0.7826 ≒ 0.2174（約21.7%）
```

3条件すべてがそろう確率は約21.7%、つまりおよそ4〜5回に1回しか「理想の初手」は訪れない計算になります。

ここで単純に3つの単独確率（B：約70.6%、E：約79.0%、T：約44.5%）をそのまま掛け合わせた場合、`0.706×0.790×0.445 ≒ 0.248`（約24.8%）となり、実際の約21.7%よりやや高く出てしまいます。これは初手8枚という決まった枠を3種類のカードが取り合っているため、わずかに負の相関が生じるためです。単独確率の掛け算は目安にはなりますが、正確な数字を知りたい場合は必ず包除原理で計算する必要があります。

## 採用枚数を増やすとどう変わるか・実戦での考察

冒頭の表の通り、エネルギー10枚・キートレーナーズ4枚を固定してたねポケモンの採用枚数だけを増やしても、3条件同時成立率は約13.2%（4枚）→約27.1%（12枚）までしか伸びません。たねポケモン単独のヒット率は4枚で約44.5%、12枚で約85.3%と大きく伸びているにもかかわらず、全体の足を引っ張っているのは他の2条件、特に単独確率が最も低いキートレーナーズ（4枚採用で約44.5%）です。

実際に、たねポケモン8枚・エネルギー10枚を固定してキートレーナーズの採用枚数だけを変えると、次のようになります。

| キートレーナーズ採用枚数 | 3条件同時成立確率 |
|---|---|
| 1枚 | 約6.3% |
| 2枚 | 約12.0% |
| 3枚 | 約17.1% |
| 4枚 | 約21.7% |

1枚から4枚に増やすだけで約6.3%→約21.7%と3倍以上に伸びており、たねポケモンを4枚→12枚に増やす場合（約13.2%→約27.1%、2倍強）よりも効率がよいことが分かります。複数条件を同時に満たしたい場合、「全体の中でいちばん採用枚数が少ない・いちばん到達率が低い条件」を優先的に増やす方が、同じ投資枚数でも全体の成立率を効率よく引き上げられるということです。

複数条件が絡む「理想の初手」を目指す構築では、1つの条件だけを厚くするのではなく、ボトルネックになっている条件を見極めて枚数を配分することが実戦的な指針になります。

## まとめ

- たねポケモン・エネルギー・キートレーナーズのような3つの独立したカード群が初手に同時にそろう確率は、超幾何分布を使った包除原理を3条件に拡張して `1 − [ΣP(単独0枚) − ΣP(2つ同時0枚) + P(3つ同時0枚)]` で厳密に計算できる
- 代表的な採用枚数（8枚・10枚・4枚）の例では、3条件同時成立率は約21.7%にとどまり、単純な単独確率の掛け算（約24.8%）よりもやや低くなる
- 複数条件を同時にそろえたい場合は、もっとも到達率が低い条件（ボトルネック）の採用枚数を優先して増やす方が、全体の成立率を効率よく引き上げられる

自分のデッキで「本当に理想の初手」がどれくらいの確率で来ているのかを知りたい場合は、ぜひ「ポケカデッキ分析ツール」で実際の採用枚数を入力し、複数条件の組み合わせを確認してみてください。
