## はじめに

ポケモンカードゲームの強力な動きの多くは、1枚のキーカードだけでは完結せず、「グッズ」と「サポート」を組み合わせて初めて成立します。代表的な例が、ハイパーボール（グッズ）で攻撃の要になるポケモンを山札から手札に加えつつ、同じ番のうちにボスの指令（サポート）で相手のベンチにいる無防備なポケモンをバトル場へ引き出し、そのまま1ターンでしとめてしまうコンボです。

このコンボが成立するには、ハイパーボールとボスの指令の両方が同じ番の手札に揃っている必要があります。ここで見落とされがちなのが、「グッズ＋サポート」の組み合わせと「サポート＋サポート」の組み合わせでは、確率が同じでも実際の価値がまったく違うという点です。サポートは1番に1枚しか使えないという共通ルールがあるため、たとえ2種類のサポートが同時に手札へ来ても、その番のうちに両方を使うことは原理的にできません。一方グッズには枚数制限がなく、1番の中で何枚でも使えます。つまり「グッズ＋サポート」や「グッズ＋グッズ」の組み合わせでは、手札に両方そろう確率がそのまま『その番でコンボを決められる確率』になりますが、「サポート＋サポート」ではそうなりません。この記事では、超幾何分布と包除原理を使って、グッズとサポートを組み合わせたコンボが初手にそろう確率を厳密に計算し、採用枚数の配分についても考えます。

## 計算方法（超幾何分布の式）

超幾何分布の基本式は以下の通りです。

```
P(X = k) = C(K, k) × C(N-K, n-k) / C(N, n)
```

- `N`：デッキの総枚数（60枚）
- `K`：対象カードの採用枚数
- `n`：引く枚数（初手8枚）
- `k`：その中で対象カードが出た枚数

1種類のカードが初手に1枚以上来る確率は `P(X ≥ 1) = 1 − C(N-K, n) / C(N, n)` で求められます。

今回求めたいのは「グッズ（採用枚数K₁）とサポート（採用枚数K₂）の両方が初手に1枚以上そろう確率」です。これは名前の異なる2種類のカード群なので重なりがなく、包除原理を使って次のように求められます。

```
P(両方そろう) = 1 − P(グッズが0枚) − P(サポートが0枚) + P(両方0枚)

P(グッズが0枚)   = C(N−K₁, n) / C(N, n)
P(サポートが0枚) = C(N−K₂, n) / C(N, n)
P(両方0枚)       = C(N−K₁−K₂, n) / C(N, n)
```

「グッズが0枚である事象」と「サポートが0枚である事象」が同時に起こる確率を一度引いてしまうと、両方が0枚のケースを二重に引きすぎてしまうため、最後にそれを足し戻すのが包除原理のポイントです。

## 具体例

60枚デッキに、ハイパーボールを2枚、ボスの指令を3枚採用したデッキを考えます（K₁=2、K₂=3、N=60、n=8）。

まず単独の確率を求めると、

```
P(ハイパーボール≥1) = 1 − C(58, 8) / C(60, 8) ≒ 0.2509（約25.1%）
P(ボスの指令≥1)     = 1 − C(57, 8) / C(60, 8) ≒ 0.3542（約35.4%）
```

ここで単純に2つの確率を掛け合わせると 0.2509 × 0.3542 ≒ 0.0888（約8.9%）となりますが、これは正しい値ではありません。初手8枚という決まった枠を2種類のカードが取り合う形になっているため、両者はわずかに負の相関を持ち、単純な掛け算は実際の値より少し高く出てしまいます。包除原理を使った正しい計算は、

```
P(両方0枚) = C(55, 8) / C(60, 8) ≒ 0.3949
P(両方そろう) = 1 − 0.7491 − 0.6458 + 0.3949 ≒ 0.0809（約8.1%）
```

となり、正しい値は約8.1%です。単純な掛け算との差は小さいとはいえ、採用枚数を増やして精密に比較したいときほど、この誤差が結論を左右することもあるため、厳密に計算する価値があります。

## 採用枚数を増やすとどう変わるか

グッズとサポートの合計採用枚数（投資枚数）を固定したとき、2種類の枚数をどう配分するかによって、両方そろう確率は大きく変わります。合計枚数ごとに、配分を変えて比較すると次のようになります。

| 合計投資枚数 | 配分（グッズ＋サポート） | 両方そろう確率 |
|---|---|---|
| 5枚 | 1枚＋4枚 | 約5.4% |
| 5枚 | 2枚＋3枚 | 約8.1% |
| 6枚 | 1枚＋5枚 | 約6.4% |
| 6枚 | 2枚＋4枚 | 約10.2% |
| 6枚 | 3枚＋3枚 | 約11.5% |
| 8枚 | 1枚＋7枚 | 約8.1% |
| 8枚 | 2枚＋6枚 | 約13.8% |
| 8枚 | 3枚＋5枚 | 約17.2% |
| 8枚 | 4枚＋4枚 | 約18.4% |

合計枚数が同じでも、配分を均等に近づけるほど両方そろう確率は高くなります。たとえば合計8枚なら、1枚＋7枚では約8.1%にしかなりませんが、4枚＋4枚まで均等にすると約18.4%と2倍以上になります。これは、片方だけ厚く積んでも、もう片方が極端に薄いとそちらがボトルネックになってしまうためです。「同じ番で両方使う」ことが目的のコンボ用カードは、どちらか一方だけを厚くするのではなく、両方をバランスよく積む方が初手での成立率を効率よく上げられます。

もちろん実戦では、グッズとサポートで「増やしやすさ」が異なる点にも注意が必要です。グッズ側は他のサーチカードやドローサポートで多少カバーできる場面もありますが、サポートカードそのものをサーチできる手段は限られていることが多く、結局は採用枚数そのものを増やすしかないケースも多くあります。コンボの片方がサーチしにくいサポートである場合は、そちら側を気持ち厚めに配分するのも一つの考え方です。

## まとめ

- グッズとサポートを組み合わせた「同じ番で決めるコンボ」が初手にそろう確率は、超幾何分布と包除原理で `1 − P(Aが0枚) − P(Bが0枚) + P(両方0枚)` として厳密に計算できる
- 単純な「単独確率どうしの掛け算」は、初手8枚という枠を取り合う負の相関のために、実際の値よりわずかに高く出てしまう
- サポートは1番に1枚しか使えないため、「サポート＋サポート」の組み合わせは同じ確率の数字でも『その番で両方使う』ことには直結しない。グッズに枚数制限がない点が、グッズ＋サポート・グッズ＋グッズのコンボを現実的にしている
- 合計の投資枚数が同じなら、2種類の採用枚数を均等に近づけるほど両方そろう確率は高くなる。片方だけ厚く積んでも、薄い方がボトルネックになって伸びが鈍る

グッズ＋サポートのコンボを狙う構築では、「コンボ全体で何枚投資するか」だけでなく「その投資をどう配分するか」まで考えることで、同じ採用枚数でも初手での成立率を大きく変えられます。自分のデッキでどの組み合わせを狙っているか整理したうえで、「ポケカデッキ分析ツール」で枚数を変えながら確率の変化を確認してみてください。
