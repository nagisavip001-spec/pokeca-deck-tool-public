| 用語 | 意味 | 補足 |
|---|---|---|
| たねポケモン | 進化前の、何もかけ合わせずに場に出せるポケモン | カード左上に進化マークがない。バトル場・ベンチに直接出せる唯一のポケモン |
| 進化ポケモン（1進化・2進化） | たねポケモンから進化させたポケモン | 手札から直接は出せず、対応するポケモンの上に重ねて進化させる必要がある |
| バトル場 | お互いが対戦中に技を出し合う1匹だけの特別な場所 | ここにいるポケモンだけが攻撃を受け、倒されるとサイドを取られる |
| ベンチ | バトル場以外にポケモンを置いておける場所 | 最大8匹まで（カードの効果で変動する場合あり）。控えのポケモンはここで待機する |
| エネルギー | ポケモンが技を出すために必要なカード | 手動で付けられるのは通常1ターンに1枚。効果でまとめて付けられる場合もある |
| トラッシュ | 使用済みのカードや倒れたポケモンを置く場所 | 一度置かれたカードは、特定の効果がない限り手札やデッキに戻らない |
| サイド | ゲーム開始時に山札から6枚裏向きで分けておくカード | 相手のポケモンを倒すたびに1〜3枚を手札に加えられる。0枚になると勝利条件のひとつを満たす |
| マリガン | 初手7枚にたねポケモンが1枚もないときの引き直し | 手札をすべて山札に戻してシャッフルし、再び7枚引く。相手にはマリガン回数分ドローする権利が発生する |
| ワザ（技） | ポケモンが持つ攻撃手段 | 必要なエネルギーの種類・数を満たしていないと使えない |
| どく・やけど等の特殊状態 | ポケモンに一時的にかかる不利な状態 | 「どく」「やけど」は自分の番の終わりに毎回ダメージが入るなど、状態ごとに処理タイミングが異なる |
| グッズ | 手札から好きなタイミングで使えるトレーナーズカード | 1ターンに使える枚数の制限は基本的にない（カード自体の制約は個別に確認） |
| サポート | 1ターンに1枚しか使えない強力なトレーナーズカード | ドロー加速やサーチなど、ゲームを大きく動かす効果が多い |
| スタジアム | 場に1枚だけ置いておける、両プレイヤーに影響するトレーナーズカード | 新しいスタジアムを出すと、それまでのスタジアムはトラッシュされる |

## はじめに

ポケモンカードを始めたばかりだと、対戦相手や動画で飛び交う「たねポケモン」「ベンチ」「サイド」といった言葉の意味がつかみきれず、ルールブックを読んでも頭に入ってこない、ということがよくあります。この記事では、まず基本用語を表で整理し、そのあとに実際のゲームがどんな流れで進むのかを順番に見ていきます。確率計算の話は出てきませんが、これから他の記事を読み進めるための土台として役立つはずです。

## ゲームの流れ：対戦開始からセッティングまで

対戦は、おおまかに次のような順番で進みます。

1. **デッキとサイドの準備**：60枚のデッキをシャッフルし、山札の上から6枚を裏向きのままサイドとして分けておきます。残りが自分の山札になります。
2. **初手7枚を引く**：山札の上から7枚を手札として引きます。この中にたねポケモンが1枚もなければ、マリガンとして手札を山札に戻し、シャッフルして引き直します。
3. **バトル場とベンチにポケモンを出す**：手札のたねポケモンの中から1匹をバトル場に、残りは任意でベンチに（最大8匹まで）裏向きで並べます。
4. **先攻・後攻を決めてゲーム開始**：先攻・後攻を決める方法は大会のレギュレーションによって異なりますが、決まったらすべてのポケモンを表向きにし、対戦がスタートします。

## 自分の番でできること

自分の番になったら、基本的に次のようなことができます（順番は自由で、何度でも行えるものと回数制限があるものが混ざっています）。

- **山札から1枚ドローする**（先攻1ターン目は引かないルールになっていることが多い）
- **手札のたねポケモンをベンチに出す**（何匹でも可能）
- **ポケモンを進化させる**（ただし、そのポケモンが場に出たターンには進化できない。場に出した直後の番は進化不可）
- **エネルギーを1枚、手札からポケモンに付ける**（1ターンに1枚が基本）
- **グッズを好きな枚数使う**
- **サポートを1枚使う**（1ターンに1枚まで）
- **スタジアムを1枚出す**
- **ポケモンを入れ替える**（特性やアイテムを使わない通常の入れ替えは1ターンに1回）
- **技を1つ使って攻撃する**（技を使うとその番の残りの行動が終了し、相手の番に移る）

このうち「技を使う」ことだけが、その番の最後の行動になります。技を使わずに番を終える（エネルギーを溜めるだけで攻撃しない）という選択肢もよく使われます。

## 勝敗条件

ポケモンカードの勝利条件は、主に次の3つです。

- **相手のサイドが0枚になる**：相手のポケモンを倒すたびにサイドを1〜3枚（倒したポケモンの種類による）取っていき、最初の6枚をすべて取り切ると勝利
- **相手の場にポケモンが1匹もいなくなる**：バトル場のポケモンが倒され、ベンチにも控えのポケモンがいない状態になると、その時点で敗北
- **相手が山札切れになる**：自分の番の最初にドローしようとして山札が0枚だと、その時点で敗北

サイドを取ることだけに気を取られがちですが、「相手の場を空にする」ことも立派な勝ち筋のひとつです。特にベンチ育成が遅いデッキ相手には、この勝ち方が視野に入ることもあります。

## まとめ

- たねポケモンは進化ポケモンの土台であり、唯一手札から直接場に出せるポケモンである
- バトル場は攻撃を受ける唯一の場所、ベンチは控えのポケモンを待機させておく場所
- サポートは1ターン1枚、エネルギーの手動付与も基本は1ターン1枚という「1ターンの制約」を覚えておくと動きの計画が立てやすい
- 勝利条件は「サイド0枚」「相手の場が空になる」「相手の山札切れ」の3種類
