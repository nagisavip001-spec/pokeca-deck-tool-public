## マリガンとは何か

ポケモンカードでは、初手7枚（マリガンのルールが適用されるのは7枚判定）の中に「たねポケモン」が1枚も含まれていないと、手札を全て山札に戻して引き直す「マリガン」という処理が発生します。マリガンになると、相手はサイドを1枚多く見られるうえに、自分は場にポケモンを1体も出せない状態からのスタートを強いられるため、対戦において大きく不利な状況を招きます。

「たねポケモンを何枚採用すればマリガンを避けられるのか」は、デッキ構築の初期段階で必ず検討すべきポイントです。この記事では、たねポケモンの採用枚数ごとにマリガンになる確率を超幾何分布で計算し、その目安を確認していきます。

## 超幾何分布による計算方法

マリガンになる確率は、「初手7枚の中にたねポケモンが1枚も含まれない確率」と言い換えられます。これは超幾何分布の `k = 0` のケースにあたります。

```
P(X = 0) = C(K, 0) × C(N-K, n) / C(N, n) = C(N-K, n) / C(N, n)
```

- `N`：デッキの総枚数（通常60枚）
- `K`：デッキ内のたねポケモンの採用枚数
- `n`：引く枚数（マリガン判定は7枚）
- `k`：その中にたねポケモンが含まれる枚数（マリガンなので0を考える）

`C(K, 0) = 1` なので、この式は「たねポケモン以外のカード（N-K枚）だけから7枚を選ぶ組み合わせ」を「デッキ60枚から7枚を選ぶ組み合わせ」で割った形になります。たねポケモンを1枚も引かない、つまり残り52枚（K=8の場合）だけから7枚が選ばれるケースの割合を求めている、とイメージすると分かりやすいでしょう。

## 具体例：たねポケモン8枚採用の場合

実際に数字を当てはめてみます。たねポケモンを**8枚**採用しているデッキで、初手7枚がマリガンになる確率を計算します。

- `N = 60`
- `K = 8`
- `n = 7`
- `k = 0`

```
P(X = 0) = C(52, 7) / C(60, 7) ≒ 0.346（約34.6%）
```

つまり、**たねポケモンを8枚採用していても、約3回に1回はマリガンになる**という計算です。これは意外と高い数字に感じる方も多いのではないでしょうか。ポケカのデッキはトレーナーズやエネルギーの枠も必要になるため、たねポケモンの採用枚数はどうしても限られがちですが、この確率を知っておくと採用枚数の判断がしやすくなります。

## 採用枚数を増やすとどう変わるか

冒頭の表からも分かる通り、たねポケモンの採用枚数を増やすほどマリガン率は下がっていきますが、その下がり方は一様ではありません。

たとえば4枚から8枚に増やすとマリガン率は60.1%→34.6%と大きく改善しますが、8枚から12枚に増やしても34.6%→19.1%と改善幅は小さくなっていきます。さらに16枚から20枚では9.9%→4.8%と、絶対値としての改善幅はより小さくなります。これは超幾何分布特有の収穫逓減の性質で、採用枚数が少ないうちほど1枚の増減が確率に与える影響が大きいということです。

一般的には、たねポケモンを**8〜10枚前後**採用するとマリガン率が20〜35%程度に収まり、実戦での事故率と枠のバランスが取りやすいとされています。ただし多進化ラインを複数採用するデッキや、たねポケモン自体が少なくても機能するデッキ（トラッシュ活用型など）では最適な枚数が変わってくるため、あくまで目安として捉えてください。

## サイド落ちも合わせて考える

マリガン率だけでなく、たねポケモンがサイド（6枚）に落ちてしまう確率も、実戦では無視できない要素です。マリガンを避けられても、キーとなるたねポケモンがサイドに複数枚埋まってしまうと、思うように展開できないことがあります。こうした複合的な確率は、デッキリストをそのまま入力してシミュレーションできる「ポケカデッキ分析ツール」を使うと、採用枚数ごとの違いを手軽に比較できます。

## まとめ

- マリガンになる確率は超幾何分布の `P(X=0) = C(N-K, n) / C(N, n)`（n=7）で計算できる
- たねポケモン8枚採用でもマリガン率は約34.6%と、意外に高い
- 採用枚数が少ない領域ほど、1枚増やすことの効果が大きい
- 一般的には8〜10枚前後の採用でマリガン率と枠のバランスが取りやすい

たねポケモンの採用枚数に迷ったときは、感覚だけに頼らず、実際の確率を確認しながらデッキを組んでみてください。
