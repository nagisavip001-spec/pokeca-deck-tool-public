## はじめに

「キーカードを初手でちょうど1枚引けた。残りの採用枚数は山札のどこかにあるはずだから、そのうち引けるだろう」――そう思っていたら、実は残りが全部サイドに埋まっていて、サイドを取り切るまで二度と引けなかった、という経験はないでしょうか。

ポケモンカードでは、デッキ60枚は「初手（手札）」「サイド6枚」「残りの山札」の3つに分かれて配られます。初手に来なかったカードは、サイドに埋まっているか、まだ山札に残っているかのどちらかです。もし残りの採用枚数がすべてサイドに埋まってしまうと、そのカードは実質的に「サイドを相応に取るまで入手できない」状態になり、1枚採用のカードがサイド落ちする場合と同じように、ゲームの再現性を大きく損ないます。

この記事では、「初手にキーカードがちょうど1枚だけ来た」という条件のもとで、残りの採用枚数がすべてサイドに埋まってしまう確率を、超幾何分布を2段階に組み合わせて厳密に計算します。

## 計算方法（超幾何分布の式）

この問題は、超幾何分布を2段階に重ねて考える必要があります。

**ステップ1：初手にちょうど1枚来る確率**

```
P(初手にj枚) = C(K, j) × C(N-K, n-j) / C(N, n)
```

- `N`：デッキの総枚数（60枚）
- `K`：対象カードの採用枚数
- `n`：初手の枚数（8枚）
- `j`：初手に含まれる対象カードの枚数（ここでは `j = 1`）

**ステップ2：残りの採用枚数が、サイドと山札にどう振り分けられるか**

初手に1枚来たということは、残り `K-1` 枚は、初手に使われなかった `N-n = 52` 枚（サイド6枚＋残り山札46枚）の中に、ランダムな位置で存在しています。そのうち何枚がサイド6枚の側に入るかも、超幾何分布で計算できます。

```
P(残りのうちm枚がサイドに入る) = C(6, m) × C(46, (K-1)-m) / C(52, K-1)
```

残りの採用枚数（`K-1`枚）が「全てサイドに埋まる」確率は、このステップ2の式に `m = K-1` を代入したものです。最終的に知りたい「初手1枚＆残り全滅」の同時確率は、ステップ1とステップ2を掛け合わせることで得られます。

```
P(初手1枚 かつ 残り全滅) = P(初手にちょうど1枚) × P(残りのK-1枚が全てサイドに入る)
```

## 具体例：2枚採用の場合

もっとも分かりやすい2枚採用のケースで数字を当てはめてみます。

- `N = 60`、`K = 2`、`n = 8`
- ステップ1：初手にちょうど1枚来る確率 `P(j=1) = C(2,1) × C(58,7) / C(60,8) ≒ 0.235`（約23.5%）
- ステップ2：残り1枚がサイド6枚の側に入る確率 `C(6,1) × C(46,0) / C(52,1) = 6/52 ≒ 0.115`（約11.5%）
- 同時確率：`0.235 × 0.115 ≒ 0.027`（約2.7%）

つまり、2枚採用のキーカードが初手にちょうど1枚だけ来た場合、**約11.5%の確率でもう1枚はサイドに埋まっている**ことになります。これは直感的にも納得しやすい数字です。初手に来なかった52枚のうち、サイドはちょうど6枚（52枚中の約11.5%）を占めているため、残り1枚がランダムにその中へ入り込む確率もほぼ同じ比率になる、というシンプルな理屈です。

一方で、同時確率（初手にちょうど1枚かつ残りが全滅）で見ると約2.7%まで下がります。これは「初手1枚」という条件自体が約23.5%しか起こらないためです。実戦で問題になるのは条件付き確率（約11.5%）の方で、「初手にキーカードを1枚引けて一安心していたら、実は残りの1枚もサイドに埋まっていた」という状況は、8回に1回程度の頻度で起こり得ると考えておく必要があります。

## 採用枚数を増やすとどう変わるか

冒頭の表を見ると、採用枚数を増やすほど「残りが全てサイドに埋まる確率」は急速に下がっていくことが分かります。2枚採用では約11.5%ですが、3枚採用（残り2枚が両方サイドに入る確率）では約1.1%、4枚採用（残り3枚が全てサイドに入る確率）では約0.1%まで下がります。

これは、サイドがたった6枚しかない狭い枠であるため、「埋めなければならない残り枚数」が増えるほど、その全部がこの狭い枠に収まる確率が指数的に小さくなるためです。逆に言えば、**1枚採用（K=1）のカードには「残り」という概念自体が存在しないため、初手に来なければそのまま100%サイドか山札のどちらかで終わり**ですが、2枚以上採用しておくことで「1枚は手札に来たのに、残り全部が詰む」という最悪の事態を大きく減らせるということです。

実戦的には、1枚しか採用できない特殊なカード（ACE SPEC枠や、効果上1枚しか入れられないカードなど）については、このリスクをそもまま受け入れるしかありません。しかし通常のキーカードであれば、2枚採用から3枚採用に増やすだけで「残り全滅」のリスクを約1/10に抑えられる、という点は、採用枚数を検討する際の有力な根拠になります。特に「初手に1枚引けたから大丈夫」と考えてしまいがちな場面こそ、実はまだ事故の可能性が残っていることを意識しておくとよいでしょう。

## まとめ

- 初手に来なかったキーカードの残りは、サイド6枚か残り山札のどちらかにランダムに存在する
- 初手にちょうど1枚来た場合、2枚採用なら残りの1枚が約11.5%の確率でサイドに埋まってしまう
- 採用枚数を増やすほど「残りが全てサイドに埋まる」確率は指数的に下がり、3枚採用では約1.1%、4枚採用では約0.1%まで低下する
- 「初手に1枚引けた」という安心感に反して、残りがサイドに埋まり切っているリスクは採用枚数が少ないほど無視できない

キーカードの採用枚数を1枚から2枚、2枚から3枚に増やす判断に迷ったときは、初手ヒット率だけでなく、こうした「手札とサイドの同時確率」も踏まえて検討してみてください。
