## はじめに

デッキに採用できるサーチ用のグッズは1種類だけではありません。「ネストボール」のようにたねポケモン専用のサーチと、「ハイパーボール」のように手札2枚をトラッシュする代わりに山札のどんなポケモンでも探せるサーチを、両方採用しているデッキも多いはずです。

ここで気になるのが、「両方のサーチカードを増やせば、目当てのポケモンへの実質的な到達率も素直に伸びていくのか」という点です。以前の記事では、サーチカード1種類を目当てのポケモンに足し算できることを確認しました。しかし、ネストボールは効果テキスト上「たねポケモン」しか対象にできないため、目当てが1進化・2進化ポケモンだった場合、ネストボールは山札の中にその進化ポケモンがいくら残っていても一切手札（ベンチ）に呼び出せません。つまり、2種類のサーチカードを採用枚数の合計だけで単純に捉えると、計算を大きく見誤ることがあります。

この記事では、目当てのポケモンが「たねポケモン」か「1進化ポケモン」かで、2種類のサーチカードの実質的な寄与がどう変わるのかを超幾何分布で厳密に計算し、採用枚数を増やす際に見落としがちな落とし穴を具体的な数字で確認します。

## 計算方法（超幾何分布の式）

超幾何分布の基本式はこうでした。

```
P(X = k) = C(K, k) × C(N-K, n-k) / C(N, n)
```

- `N`：デッキの総枚数（通常60枚）
- `K`：対象カードの採用枚数
- `n`：引く枚数（初手8枚）
- `k`：その中に対象カードが含まれる枚数

以前の記事で確認したとおり、「目当てのポケモン（K<sub>t</sub>枚）」と「サーチカード（K<sub>s</sub>枚）」のどちらかが初手にあれば実質的に到達できたとみなす場合、両方とも0枚になる確率は、両方を合わせた「どちらでもないカード」の中からn枚を選ぶ場合の数で求められます。

```
P(到達失敗) = C(N − K_t − K_s, n) / C(N, n)
P(実質到達) = 1 − C(N − K_t − K_s, n) / C(N, n)
```

ここで重要なのは、この足し算が成立するのは「そのサーチカードが、目当てのポケモンを実際に探し出せる」場合に限られるという前提です。ネストボールとハイパーボールを両方採用している場合、目当てのポケモンがたねポケモンなら、

```
P(実質到達) = 1 − C(N − K_t − K_nest − K_hyper, n) / C(N, n)
```

という3項の足し算になりますが、目当てのポケモンが1進化ポケモンだった場合、ネストボールは対象外になるため`K_nest`の項はそもそも式に加えることができません。

```
P(実質到達) = 1 − C(N − K_t − K_hyper, n) / C(N, n)　（K_nestは計算に加わらない）
```

対象制限のあるサーチカードは、「採用枚数」ではなく「目当てのカードを実際に探せるかどうか」で初めて式に加算できる、という点がこの記事のポイントです。

## 具体例

デッキ60枚の中に、目当てのポケモンを1枚だけ採用（K<sub>t</sub>=1）し、ネストボール4枚、ハイパーボール4枚を採用したケースで比較します。

**目当てがたねポケモンの場合**（ネストボールもハイパーボールも対象にできる）

```
N = 60、K_t + K_nest + K_hyper = 1 + 4 + 4 = 9
P(到達失敗) = C(51, 8) / C(60, 8) ≒ 0.2489
P(実質到達) = 1 − 0.2489 ≒ 0.7511（約75.1%）
```

**目当てが1進化ポケモンの場合**（ネストボールは対象外）

```
N = 60、K_t + K_hyper = 1 + 4 = 5（ネストボール4枚は式に加わらない）
P(到達失敗) = C(55, 8) / C(60, 8) ≒ 0.4759
P(実質到達) = 1 − 0.4759 ≒ 0.5241（約52.4%）
```

同じ「ネストボール4枚＋ハイパーボール4枚」という投資でも、目当てがたねポケモンなら約75.1%まで到達率が伸びるのに対し、1進化ポケモンだと約52.4%で頭打ちになります。両者の差（約22.7ポイント）は、まるごとネストボール4枚分の採用が無駄になっていることに相当します。

## 採用枚数を増やすとどう変わるか、または実戦での考察

冒頭の表の通り、目当てが1進化ポケモンの場合、ネストボールを0枚から4枚に増やしても実質到達率は約13.3%のまま一切変化しません。これは「採用枚数を増やしたのに数字がまったく動かない」という、見落としやすい典型例です。一方でハイパーボールを0枚から4枚に増やすと、同じ条件でも約13.3%→約52.4%としっかり伸びます。

この違いが生まれる理由は単純で、ネストボールの効果テキストが「たねポケモンを1枚選び、ベンチに出す」に限定されているためです。山札に目当ての1進化ポケモンが何枚残っていても、ネストボールでは物理的に探し出せません。実戦でよくあるのは、「サーチ札をたくさん積んでいるから大丈夫」と考えて採用枚数だけを見てしまい、肝心のアタッカーが1進化・2進化ポケモンだった場合に、実際に効いているサーチ札がハイパーボールや該当する専用サーチカードだけだった、というケースです。

対策としては、以下の2点を採用枚数検討の際に確認するとよいでしょう。

- **目当てのポケモンの進化段階を確認する**：たねポケモンであればネストボール・ハイパーボールのどちらも足し算の対象になりますが、1進化・2進化ポケモンの場合はハイパーボールや「ともだちてちょう」のような進化ポケモンも探せるサーチカードしか計算に加えられません。
- **ハイパーボールの手札コストも忘れない**：ハイパーボールは手札からカードを2枚トラッシュする必要があります。初手8枚の時点ではほぼ問題になりませんが、終盤に手札が薄くなっている場面では「サーチカードはあるのに撃てない」という事故も起こり得ます。

## まとめ

- 2種類のサーチカードを併用する場合、実質到達率の式に足し算できるのは「そのサーチカードが実際に目当てのポケモンを探せる」場合に限られる
- ネストボールのようにたねポケモン専用のサーチカードは、目当てが1進化・2進化ポケモンだと採用枚数を増やしても実質到達率に一切寄与しない
- 同じ「ネストボール4枚＋ハイパーボール4枚」でも、目当てがたねポケモンなら約75.1%、1進化ポケモンなら約52.4%と、進化段階だけで約22.7ポイントの差が生まれる
- サーチカードの採用枚数を検討する際は、合計枚数だけでなく「そのカードが本当に目当てを探せるか」を必ず確認する

サーチカードを増やすこと自体は安定感を高める有効な手段ですが、「何を探せるカードなのか」を取り違えると、積んだ枚数の一部がまるごと無駄になってしまいます。自分のデッキでどのサーチカードがどの枚数分の価値を持っているのか気になる方は、「ポケカデッキ分析ツール」で目当てのポケモンの進化段階に応じた採用枚数を一度整理してみてください。
